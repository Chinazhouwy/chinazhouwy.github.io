# 第227题：自我介绍与主线串联（简历专项 01）

## 题目
请分别用 90 秒和 3 分钟完成自我介绍，如何把保险金融、Java 后端、组长经验和 AI Agent 串成一条主线？

## 用户原始回答
> 这太扯淡了，好无聊的问题。实际面试中我就是按时间线串项目：平安 10 年，从电商销售→保险销售→商机管理→移动端后台→代理人逻辑→AI 客服→AI 智能工作台。90 秒太长了，我不会那样讲。

## 评分与扣分点

**评分：3/10**

- 实际表达的自我介绍方向正确：按时间线串项目经历
- 但拒绝按题目要求练习结构化自我介绍
- 缺乏时间控制意识（90秒 vs 3分钟）
- 没有把 Java 后端、组长经验、AI Agent 三条线主动串起来

## 完整答案

### 90 秒版本（约 200 字）

> 我在平安有 10 年后端开发经验，从传统 Java 一路做到 AI Agent。早期主要负责保险电商和销售管理系统，后来带 5 人后端小组做商机管理平台和移动端后台。近两年转向 AI 方向，主导了保险 AI 客服从 0 到 1 的落地，包括 RAG 知识库、Function Calling 工具接入、SSE 流式链路，同时个人也在做 Agent Harness 框架的探索。技术栈是 Java/Spring Boot/MySQL/Redis，对分布式事务、高并发和系统稳定性有实战经验。

### 3 分钟版本（约 400 字）

> 我在平安集团有 10 年后端经验，经历三个阶段：
>
> **第一阶段（前 5 年）—— Java 基础 + 业务落地。** 负责保险电商平台、销售管理系统，涵盖投保出单、代理人管理、商机活动等核心链路。技术栈 Java + Spring + Oracle/MySQL，积累了分布式事务（TCC/本地消息表）、慢 SQL 优化、报表性能调优的实战经验。
>
> **第二阶段（中间 3 年）—— 架构升级 + 团队管理。** 带 5 人后端小组，主导 Ant 到 Maven、Spring 3 到 Spring Boot、Oracle 到 OceanBase 的技术迁移，自研了 MyBatis 分页插件、Redis 分布式锁组件。负责核心报表从分钟级优化到秒级，百万行 Excel 导出的 OOM 治理。
>
> **第三阶段（近 2 年）—— AI Agent 转型。** 从 0 搭建保险 AI 客服，设计 RAG 检索链路（混合检索 + Reranker）、Function Calling 工具接入、SSE 流式输出，处理模型超时、限流、熔断和人工兜底。个人项目 MiniHarness 探索 Agent Runtime 框架，涉及 Spring AI、结构化输出、Memory 管理和 Tool Loop 控制。
>
> 我现在的定位是：有 Java 后端深厚功底、能带团队、能从 0 到 1 落地 AI Agent 产品的全栈后端工程师。
