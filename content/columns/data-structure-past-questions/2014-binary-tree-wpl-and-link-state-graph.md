# 2014 · 二叉树带权路径长度与链路状态建图

> 卷面位置：2014 年综合卷 第 41 题（13 分）、第 42 题（10 分）。原卷为扫描件，题 42 的拓扑与链路状态表数值以卷面为准。

## 第 41 题（13 分）：求二叉树的带权路径长度（WPL）

二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树 T，采用二叉链表存储，结点结构为 `left | weight | right`，其中叶结点的 weight 域保存该结点的非负权值。设 root 为指向 T 的根结点的指针，请设计求 T 的 WPL 的算法。要求：给出算法的基本设计思想；使用 C/C++ 给出二叉树结点的数据类型定义；根据设计思想描述算法，关键之处给出注释。

## 考点

- WPL 只统计叶结点，非叶结点的 weight 不参与；
- 路径长度 = 层数 - 1（根的深度为 0）；
- 递归时把 depth 作为参数往下传，而不是回头去查层数。

## 思路

递归函数 `wplOf(root, depth)`：

- 空结点返回 0；
- 叶结点（left、right 都为 NULL）返回 `depth * root->weight`；
- 否则返回左右子树在 depth+1 层的 WPL 之和。

也可以用层次遍历（队列里同时存深度），遇到叶结点累加，时间同为 O(n)，但空间从递归栈的 O(h) 变成 O(w)。

## 参考实现（C）

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *left, *right;
} BiTNode, *BiTree;

int wplOf(BiTree root, int depth) {
    if (root == NULL) return 0;
    if (root->left == NULL && root->right == NULL)
        return depth * root->weight;              /* 只算叶结点 */
    return wplOf(root->left, depth + 1) + wplOf(root->right, depth + 1);
}

int WPL(BiTree root) {
    return wplOf(root, 0);                        /* 根深度为 0 */
}
```

## 复杂度

- 时间：O(n)，每个结点访问一次；
- 空间：O(h)，递归栈深度等于树高。

## 容易丢分的地方

- 把非叶结点的 weight 也算进 WPL；
- 根深度取 1，结果整体偏大（叶结点个数 × 1）；
- 叶结点判定写成「左孩子为空」；
- 忘记单独写数据类型定义——这题明确有 2 分在这上面。

## 第 42 题（10 分）：从链路状态信息到图

题 42 表是路由器 R1 维护的主要链路状态信息（LSI），题 42 图是据此构造的网络拓扑。要求：

1. 本题中的网络可抽象为数据结构中的哪种逻辑结构？
2. 针对表中的内容，设计合理的链式存储结构以保存链路状态信息，给出数据类型定义并画出对应题 42 表的链式存储结构示意图（示意图中可仅以 ID 标识结点）；
3. 按照迪杰斯特拉（Dijkstra）算法的策略，依次给出 R1 到达题 42 图中子网 192.1.x.x 的最短路径及费用。

**第 1 问：** 无向带权图（网络中的路由器、子网为顶点，链路与费用为边和权）。

**第 2 问：** 邻接表。顶点表项存本端 ID、IP、类型（路由器/子网，题面表中 R 与 N 两类），边表项存对端 ID、对端 IP、Metric（费用）与指针。用邻接表而不是邻接矩阵的理由：链路状态是稀疏的，一台路由器的邻居数量远小于网络规模，邻接表 O(n+e) 空间，便于按邻居扩展；矩阵则是 O(n²)。

**第 3 问：** 用 Dijkstra 从 R1 出发，维护 `dist[]` 与 `path[]`（前驱），每轮选未确定集合中 dist 最小的顶点并入，对邻居做松弛。**答题时必须按轮次写出每次被并入的顶点、更新后的 dist 与最终路径**，只写最终结果会丢过程分。具体权值以卷面 LSI 表为准，代入上面步骤逐轮算即可。

**易错点：** 把 LSI 表里的 Metric 当成跳数（题面同一对端点可能有多条链路）；把子网顶点漏掉（子网也算顶点）。
