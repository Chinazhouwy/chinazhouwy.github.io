# 2017 · 表达式树转中缀表达式

> 卷面位置：2017 年综合卷 第 41 题（15 分）、第 42 题（8 分）。第 42 题的图与权值以卷面为准。

## 第 41 题（15 分）：把表达式树输出成中缀表达式

请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。要求：给出算法的基本设计思想；使用 C/C++ 给出二叉树结点的数据类型定义；根据设计思想描述算法，关键之处给出注释。

## 考点

- 中序遍历得到中缀序列（左-根-右）；
- 括号只在「分支结点作为子表达式」时加，根结点不加；
- 叶结点是操作数，不需要括号。

## 思路

`inorder(root, depth)`：

- 空树直接返回；
- 叶结点：输出操作数；
- 非叶结点：`depth > 0` 时先输出 `(`，递归左子树，输出根结点的操作符，递归右子树，再输出 `)`。

根调用时 depth = 0，因此最外层没有括号；其余分支结点都会带一层括号，正好反映计算次序。

## 参考实现（C）

```c
typedef struct BiTNode {
    char data;                       /* 叶结点存操作数，分支结点存运算符 */
    struct BiTNode *left, *right;
} BiTNode, *BiTree;

void inorder(BiTree root, int depth) {
    if (root == NULL) return;
    if (root->left == NULL && root->right == NULL) {
        printf("%c", root->data);    /* 操作数 */
        return;
    }
    if (depth > 0) printf("(");      /* 分支结点且不是整棵树的根 */
    inorder(root->left, depth + 1);
    printf("%c", root->data);        /* 运算符 */
    inorder(root->right, depth + 1);
    if (depth > 0) printf(")");
}
```

## 复杂度

- 时间：O(n)，每个结点访问一次；
- 空间：O(h)，递归栈。

## 容易丢分的地方

- 每个结点都加括号（结果里出现 `((a+b))` 这类多余括号）；
- 根结点也加括号；
- 用先序或后序输出，得到的不是中缀表达式；
- 只输出字符不处理括号层级，等价性丧失。

## 第 42 题（8 分）：从 A 出发的 Prim 最小生成树

题面给出一个带权无向图，要求从顶点 A 开始，用 Prim 算法构造最小生成树，按加入次序写出每次选中的边及权值，并给出最小生成树的代价。

**解题步骤（必须写出「候选边集合」）：**

1. 初始 U = {A}，候选边 = A 的所有关联边；
2. 每轮从「一端在 U、另一端不在 U」的边中选权值最小的，把新顶点并入 U，并把它到 U 的边加入候选集；
3. 重复 n-1 轮，直到所有顶点都在 U 中；
4. 代价 = 选中的 n-1 条边权值之和。

**易错点：** 选边时只在「已选顶点」与「未选顶点」之间选，误选了两个都在 U 内的边；把 Prim 和 Kruskal（全局按权排序 + 判环）混用；忘记说明该算法时间与顶点数、边数的关系（邻接矩阵 O(n²)，邻接表 + 堆 O(e log n)）。

具体顶点与权值以卷面题 42 图为准，按上述步骤逐轮填表即可。
