# 2016 · 正则 k 叉树的结点计数与集合划分

> 卷面位置：2016 年综合卷 第 41 题是网络题，数据结构综合题为第 42 题和第 43 题。分值以卷面为准。

## 第 42 题：正则 k 叉树的结点计数

如果一棵非空树 T（k ≥ 2）中每个非叶结点都有 k 个孩子，则称 T 为正则 k 叉树。请回答下列问题并给出推导过程：

1. 若 T 有 n 个非叶结点，则 T 中的叶结点有多少个？
2. 若 T 的高度为 h（h ≥ 1），则 T 的结点数最多为多少个？最少为多少个？

**第 1 问：叶结点数 = n(k-1) + 1。**

推导（用边数等价关系）：设叶结点数为 m，总结点数 N = n + m。总边数既是 N - 1（树的性质），又等于每个非叶结点贡献 k 条边，即 nk。于是：

```text
N - 1 = nk  →  n + m - 1 = nk  →  m = n(k - 1) + 1
```

**第 2 问：最多 (kʰ - 1)/(k - 1)，最少 1 + (h - 1)k。**

- 最多：每个非叶结点都尽量放在上面，形成满 k 叉树，各层结点数为 1, k, k², …, k^(h-1)，求和得 (kʰ - 1)/(k - 1)；
- 最少：高度固定为 h，则第 1 层到第 h-1 层每层至少要有 1 个非叶结点。第 1 层 1 个（非叶）→ 第 2 层恰有 k 个；第 2 层中取 1 个非叶 → 第 3 层恰有 k 个……依次下去，第 2 层到第 h 层各恰 k 个结点，合计 1 + (h - 1)k。

**易错点：** 把高度 h 当成层数 h+1 处理（最多结点的公式整体错位一层）；最少情况误以为各层都是 1 个结点（正则 k 叉树下不可能，非叶必然长出 k 个孩子）。

## 第 43 题：|元素个数差| 最小且 |元素和差| 最大

已知由 n（n ≥ 2）个正整数构成的集合 A = {ak | 0 ≤ k < n}，将其划分为两个不相交的子集 A₁ 和 A₂，元素个数分别是 n₁ 和 n₂，元素之和分别是 s₁ 和 s₂。设计一个尽可能高效的划分算法，满足 |n₁ - n₂| 最小且 |s₁ - s₂| 最大。要求：给出基本设计思想；用 C/C++ 描述算法，关键之处给出注释；说明平均时间复杂度和空间复杂度。

## 考点

- 「个数差最小」只要求两组元素个数尽量相等，与和无关；
- 「和差最大」要求把大数尽量集中到一边、小数集中在另一边；
- 两个目标可以同时满足：先排序，再按位置交替取。

## 思路

1. 把 A 降序排序：a₀ ≥ a₁ ≥ … ≥ a_{n-1}；
2. 奇数位（下标 0, 2, 4, …）放入 A₁，偶数位（下标 1, 3, 5, …）放入 A₂；
3. 于是 |n₁ - n₂| ≤ 1（n 为偶数时相等，奇数时差 1），而 A₁ 拿到的是排序后「第 1、3、5…大」的元素，A₂ 拿到「第 2、4、6…大」，A₁ 的元素逐个不小于 A₂，和差达到最大。

另一种等价写法：排序后把前 ⌊n/2⌋ 个作为一组、其余作为另一组，也能同时满足两个目标（和差最大、个数差 ≤ 1），而且代码更短。

## 参考实现（C）

```c
int cmpDesc(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return y - x;                      /* 降序 */
}

void partitionSet(int A[], int n, int *n1, int *s1, int *n2, int *s2) {
    qsort(A, n, sizeof(int), cmpDesc);  /* 第一步：降序 */
    *n1 = *n2 = *s1 = *s2 = 0;
    for (int i = 0; i < n; i++) {
        if (i % 2 == 0) { (*n1)++; *s1 += A[i]; }
        else            { (*n2)++; *s2 += A[i]; }
    }
}
```

## 复杂度

- 平均时间：O(n log n)，瓶颈在排序；
- 空间：O(1)～O(n)，取决于排序实现的栈深度。

## 容易丢分的地方

- 只满足「个数差最小」（随便分一半）或只满足「和差最大」（全部大数放一边但个数悬殊）；
- 排序方向搞反，得到的是和差最小；
- 忘记说明这两个目标为什么可以同时满足，只写代码不写论证。
