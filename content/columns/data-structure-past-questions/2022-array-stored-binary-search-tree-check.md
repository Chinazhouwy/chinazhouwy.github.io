# 2022 · 顺序存储二叉树判定二叉搜索树

> 卷面位置：2022 年综合卷 第 41 题（13 分）、第 42 题（10 分）。

## 第 41 题（13 分）：IsBST

已知非空二叉树 T 采用顺序存储结构（即用一维数组存各结点，空结点用特殊值标记），设计一个算法判断 T 是否为二叉搜索树。若 T 是二叉搜索树，返回 1，否则返回 0。要求：给出算法的基本设计思想；用 C/C++ 描述算法并注释；说明时间复杂度与空间复杂度。

## 考点

- 二叉搜索树的充要条件：**中序遍历序列严格递增**；
- 顺序存储下，下标 i（从 1 开始计）的左孩子是 2i、右孩子是 2i+1；
- 只比较「父与子」是错的——BST 要求整棵左子树都小于根，不只是左孩子。

## 思路

对顺序存储的树做一次中序遍历（递归时按 `2i`、`2i+1` 走），用一个静态变量记住上一个访问到的有效值 prev。中序访问到某个结点时：

- 若 `prev != 初始哨兵` 且 `值 <= prev`，直接判定不是 BST；
- 否则 `prev = 值`，继续。

遍历完没有违规即为 BST。空结点（哨兵值）在遍历时跳过。

也可以用显式栈做非递归中序，避免递归深度受树高限制。

## 参考实现（C）

```c
#define EMPTY 0                     /* 题面约定的空结点标记 */

int isBSTCheck(int T[], int i, int n, int *prev, int *hasPrev) {
    if (i > n || T[i] == EMPTY) return 1;      /* 越界或空结点 */
    if (!isBSTCheck(T, 2 * i, n, prev, hasPrev)) return 0;   /* 左子树 */
    if (*hasPrev && T[i] <= *prev) return 0;   /* 中序必须严格递增 */
    *prev = T[i];
    *hasPrev = 1;
    return isBSTCheck(T, 2 * i + 1, n, prev, hasPrev);       /* 右子树 */
}

int IsBST(int T[], int n) {
    int prev = 0, hasPrev = 0;
    return isBSTCheck(T, 1, n, &prev, &hasPrev);
}
```

## 复杂度

- 时间：O(m)，m 为顺序存储数组的有效长度（不是树中结点数）；
- 空间：O(h)，递归栈深度等于树高。

## 容易丢分的地方

- 只检查 `left < root < right`，漏掉「左子树的最大值也小于根」这类反例；
- 中序判定写成 `>=`，BST 不允许相等元素时判定放宽；
- 顺序存储的空结点标记与合法值冲突（如用 0 当空标记但存在值为 0 的结点）；
- 下标从 0 开始算却用 2i 找孩子。

## 第 42 题（10 分）：n 很大时取最小的 10 个数

现有 n（n > 100000）个正数，设计一个算法找出其中最小的 10 个数（要求给出时间复杂度尽可能低的算法，并说明理由）。

**结论：用一个容量为 10 的大顶堆（或小顶堆的变体），时间 O(n log 10) ≈ O(n)，空间 O(1)。**

做法：先取前 10 个数建大顶堆；随后对第 11 到第 n 个数 x，若 `x < 堆顶`，用 x 替换堆顶并向下调整；全部扫完后堆里的 10 个数就是最小的 10 个。

**为什么不用全部排序：** 全排序要 O(n log n)，而对 10 万+的数据，O(n log 10) 与 O(n) 同阶。也不建议用「建立完整小顶堆再弹 10 次」——建堆 O(n) 后每次弹出 O(log n)，虽然也是 O(n)，但空间要存全部 n 个数；容量 10 的堆只需 O(1) 额外空间。

**易错点：** 用「排序后取前 10」还声称最优；堆建成小顶堆却想取最小值（应该用大顶堆淘汰大的）；只算时间不说空间；把 10 当常数后写成 O(n) 却不说明 log 10 是常数。
