# 2018 · 未出现的最小正整数

> 卷面位置：2018 年综合卷 第 41 题（13 分）、第 42 题（12 分）。第 42 题的图以卷面为准。

## 第 41 题（13 分）：时间上尽可能高效

给定一个含 n（n ≥ 1）个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数。例如数组 {-5, 3, 2, 3} 中未出现的最小正整数是 1；数组 {1, 2, 3} 中未出现的最小正整数是 4。要求：给出算法的基本设计思想；用 C/C++ 描述算法，关键之处给出注释；说明时间复杂度与空间复杂度。

## 考点

- 「未出现的最小正整数」一定落在 [1, n+1] 内——这是全题的立足点；
- O(n log n) 的排序解法能拿部分分，O(n) 的计数/原地标记才是满分；
- 负数和 0 不参与。

## 思路

开一个长度 n+1 的标记数组 `seen[]`（下标 0..n），初值 0。遍历数组：若 `1 ≤ a[i] ≤ n`，置 `seen[a[i]] = 1`。随后从 1 开始找第一个 `seen[i] == 0` 的 i，就是答案；若 1..n 全标记过，答案是 n+1。

要 O(1) 空间的话，可以做原地标记：把值 v 换到下标 v-1 上（类似「数组中找缺失的第一个正数」的置换法），再从左到右找到第一个 `a[i] != i+1` 的位置。

## 参考实现（C）

```c
int firstMissingPositive(int a[], int n) {
    int *seen = (int *)calloc(n + 1, sizeof(int));
    for (int i = 0; i < n; i++)
        if (a[i] >= 1 && a[i] <= n) seen[a[i]] = 1;
    for (int i = 1; i <= n; i++)
        if (!seen[i]) { free(seen); return i; }
    free(seen);
    return n + 1;                    /* 1..n 都出现过 */
}
```

## 复杂度

- 时间：O(n)，两趟线性扫描；
- 空间：O(n)，标记数组（置换法可做到 O(1) 空间）。

## 容易丢分的地方

- 只返回「第一个没出现的数」而把 0 或负数算进去；
- 标记数组开成 n 而不是 n+1，值等于 n 时越界；
- 忘记 n+1 这个兜底答案；
- 排序后只看是否连续，遇到重复元素判断出错。

## 第 42 题（12 分）：光纤网络的最经济铺设方案

题面给出 5 个地区之间的光缆连接方案及建设成本（一张带权无向图），要求：

1. 求最经济的铺设方案，并说明该方案是否唯一；
2. 给出该图的存储结构（邻接矩阵或邻接表），设计求得最省费用的算法并说明时间复杂度；
3. 若相邻两个地区之间的通信需要经过的中转设备跳数超过 3 就丢弃，请设计算法回答：某个中转设备突然故障后，其余设备与地区能否正常通信。

**第 1 问：** 这就是求最小生成树，要用 Kruskal（按权从小到大选边 + 并查集判环）或 Prim。判断是否唯一：若存在「与已选边权值相等的候选边可以替换而不成环」，则方案不唯一——所以答题时要逐条列出候选边权值，指出等权边是否能互换，而不是只给出一棵树。

**第 2 问：** 5 个顶点的稠密小图，邻接矩阵更直观：`g[i][j]` 存成本，∞ 表示无直连。Prim 用邻接矩阵的时间复杂度 O(n²)，与边数无关，适合稠密图；Kruskal 需要把边排序，O(e log e)，适合稀疏图。选了哪个结构就要说清为什么。

**第 3 问：** 这是「删除一个顶点后求连通性」：从任一未故障顶点出发做 DFS/BFS，记录到达其他每个顶点经过的边数（跳数），若某顶点不可达或跳数 > 3，则判定不能正常通信；对每个可能故障的设备各做一次，总时间复杂度 O(n³)（邻接矩阵下）。

**易错点：** 最小生成树写成「最短路」（Dijkstra/Floyd 是点到点，MST 是全图连通的最小代价）；只给一个方案就断言唯一；跳数从 0 数还是从 1 数没交代清楚。
