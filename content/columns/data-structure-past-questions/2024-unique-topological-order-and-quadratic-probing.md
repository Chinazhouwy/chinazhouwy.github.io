# 2024 · 拓扑序列唯一性与二次探测散列表

> 卷面位置：2024 年综合卷 第 41 题（13 分）、第 42 题（10 分）。

## 第 41 题（13 分）：uniquely

有向图 G 采用邻接矩阵存储。工程实施需要明确各子工程的前导关系，该问题可抽象为有向图的拓扑序列问题。请设计算法 `int uniquely(MGraph G)`，判断 G 是否存在唯一的拓扑序列，若是返回 1，否则返回 0。要求：给出算法的基本设计思想；用 C/C++ 描述算法并注释。

## 考点

- 拓扑序列唯一的充要条件：**拓扑排序的每一步，入度为 0 的顶点都只有一个**；
- 存在多个入度为 0 的顶点时，它们之间没有先后约束，可以互换 → 序列不唯一；
- 还要检查是否存在环（有环则谈不上唯一，按题意返回 0）。

## 思路

1. 用邻接矩阵统计每个顶点的入度；
2. 找所有入度为 0 的顶点：个数为 0 → 有环，返回 0；个数 > 1 → 不唯一，返回 0；
3. 输出该顶点，把它所有出边的终点入度减 1；
4. 重复 n 次；全程每步入度为 0 的顶点都恰好一个 → 返回 1。

若不想修改入度数组，也可以用「已输出集合」判据：每一步统计「未输出的顶点中入度（只计未输出顶点）为 0」的个数。

## 参考实现（C）

```c
int uniquely(MGraph G) {
    int indeg[MAXV] = {0}, done[MAXV] = {0};
    for (int j = 0; j < G.numVertices; j++)
        for (int i = 0; i < G.numVertices; i++)
            if (G.Edge[i][j] != 0) indeg[j]++;

    for (int step = 0; step < G.numVertices; step++) {
        int cand = -1, cnt = 0;
        for (int i = 0; i < G.numVertices; i++)
            if (!done[i] && indeg[i] == 0) { cand = i; cnt++; }
        if (cnt != 1) return 0;        /* 0 个：有环；多个：不唯一 */
        done[cand] = 1;
        for (int j = 0; j < G.numVertices; j++)
            if (G.Edge[cand][j] != 0) indeg[j]--;
    }
    return 1;
}
```

## 复杂度

- 时间：O(n²)，每步扫一遍顶点 + 矩阵行；
- 空间：O(n)。

## 容易丢分的地方

- 只判断「图是链状」就下结论，没按算法逐步验证；
- 入度 0 的顶点个数为 0（有环）时返回 1；
- 每步从队列取一个就不再看队列长度，漏掉「同时有多个人度为 0」的情形；
- 忘记把已输出顶点的出边入度减 1，导致死循环。

## 第 42 题（10 分）：二次探测散列表

将关键字序列 20, 3, 11, 18, 9, 14, 7 依次存储到初始为空、长度为 11 的散列表 HT 中，散列函数 H(key) = (key × 3) % 11。冲突时用二次探测再散列：H_i = (H(key) + k²) % 11，k = 1, 2, 3, …。

**第 1 问：**

| key | H(key) | 结果位置 | 探测 |
|---|---|---|---|
| 20 | 60 % 11 = 5 | 5 | 1 次 |
| 3 | 9 % 11 = 9 | 9 | 1 次 |
| 11 | 33 % 11 = 0 | 0 | 1 次 |
| 18 | 54 % 11 = 10 | 10 | 1 次 |
| 9 | 27 % 11 = 5 → 占用 | 6（k=1） | 2 次 |
| 14 | 42 % 11 = 9 → 10 占用 → 2（k=2） | 2 | 3 次 |
| 7 | 21 % 11 = 10 → 0 占用 → 3（k=2） | 3 | 3 次 |

HT = `0:11, 1:空, 2:14, 3:7, 4:空, 5:20, 6:9, 7:空, 8:空, 9:3, 10:18`

装填因子 = 7/11 ≈ 0.64。

**第 2 问：查找 14 的比较序列。** H(14) = 9 → 与 HT[9] = 3 比较（不等）→ k=1 得 10，与 HT[10] = 18 比较（不等）→ k=2 得 (9+4)%11 = 2，与 HT[2] = 14 比较，命中。比较序列为 **3, 18, 14**。

**第 3 问：查找 8 失败时的散列地址。** H(8) = 24 % 11 = 2：探测序列为 2（14）、3（7）、6（9）、0（11）、7（空）——在地址 **7** 遇到空单元，判定查找失败。所以「确认查找失败时的散列地址」是 **7**（初始散列地址是 2，两者别混）。

## 复杂度

- 建表：O(n)；
- 查找：平均 O(1)，最坏退化；
- 空间：O(m)，m 为表长。

## 容易丢分的地方

- 二次探测写成线性探测（k 而不是 k²）；
- 探测过程不判「同一位置重复探测」（模 11 下 k² 会出现重复，本题未遇到，但要意识到可能无解）；
- 找 8 时答「初始散列地址 2」而没答最终判定失败的位置；
- 装填因子写成 7/11 的小数却不给分数形式之外的说明。
