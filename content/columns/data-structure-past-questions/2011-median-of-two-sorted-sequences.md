# 2011 · 两个等长升序序列的中位数

> 卷面位置：2011 年综合卷 第 41 题（8 分）、第 42 题（15 分）。原卷为扫描件，图为示意图，具体权值以卷面为准。

## 第 42 题（15 分）：中位数

一个长度为 L（L ≥ 1）的升序序列 S，处在第 ⌈L/2⌉ 个位置的数称为 S 的中位数。例如 S1 = (11, 13, 15, 17, 19)，中位数是 15；S2 = (2, 4, 6, 8, 20)，中位数是 10（按两序列合并后取中位位置的口径，题面另有约定）。现有两个等长的升序序列 A 和 B，设计一个在时间上和空间上都尽可能高效的算法，找出两个序列 A 和 B 的中位数。要求：

1. 给出算法的基本设计思想；
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释；
3. 说明所设计算法的时间复杂度和空间复杂度。

## 考点

- 「中位数」在这题里指合并后第 L 个位置的数（两序列等长，长度 L）；
- 直接归并排序是 O(n) 时间 + O(n) 空间，只能拿部分分；
- 折半淘汰：每次可稳定删掉一半元素，O(log n) + O(1)。

## 思路（折半淘汰）

设 A、B 各长 n，分别取各自当前区间的中位数 a_mid、b_mid：

1. 若 a_mid == b_mid，该值即所求；
2. 若 a_mid < b_mid，则所求中位数不可能落在 A 的左半部分和 B 的右半部分，删去这两块（为保证长度配对，删相同个数的元素）；
3. 若 a_mid > b_mid，对称处理；
4. 重复直到两个区间各剩 1 个元素，取较小者。

关键在于每次删掉的元素个数必须相等，否则会破坏「合并后第 n 个」的定位。

## 参考实现（C）

```c
int midOfTwoSorted(int A[], int B[], int n) {
    int s1 = 0, e1 = n - 1, s2 = 0, e2 = n - 1;
    while (s1 != e1 || s2 != e2) {          /* 各自剩 1 个元素时结束 */
        int m1 = (s1 + e1) / 2;
        int m2 = (s2 + e2) / 2;
        if (A[m1] == B[m2]) return A[m1];
        if (A[m1] < B[m2]) {
            /* 保留 A 的右半、B 的左半，注意奇偶对齐 */
            if ((e1 - s1 + 1) % 2 == 0) { s1 = m1 + 1; e2 = m2; }
            else { s1 = m1; e2 = m2; }
        } else {
            if ((e1 - s1 + 1) % 2 == 0) { e1 = m1; s2 = m2 + 1; }
            else { e1 = m1; s2 = m2; }
        }
    }
    return A[s1] < B[s2] ? A[s1] : B[s2];
}
```

## 复杂度

- 时间：O(log n)，每轮区间减半；
- 空间：O(1)。

## 容易丢分的地方

- 奇数、偶数长度时删掉的元素个数不一致，结果整体偏移一位；
- 用「合并后取下标 n-1」的口径去理解题目，与题面「第 ⌈L/2⌉ 个位置」的约定混淆；
- 直接归并：判卷一般给到 O(n) 方案的部分分，但时间分和空间分都会扣。

## 第 41 题（8 分）：由邻接矩阵恢复图并求关键路径

题面给出一个有向带权图 G 的邻接矩阵（按行优先压缩存储的数组），要求：画出该图；求该图的关键路径（即完成整个工程的最短时间所需的路径）及其长度；说明所用算法的时间复杂度。

**做题顺序（不要跳过第一步）。** 邻接矩阵按行优先压缩存入一维数组时，第 i 行第 j 列（j ≥ i）的元素下标为 `i*(n-i) + i*(i+1)/2 + (j-i)`（上三角口径）。恢复出 n×n 矩阵后：行 i 中 ∞ 表示无弧，非 ∞ 表示有向边 i→j 及权值。

**关键路径求解步骤：**

1. 拓扑排序，同时算事件的最早发生时间 ve：ve[源] = 0，ve[j] = max(ve[i] + w(i,j))；
2. 逆拓扑序算事件的最晚发生时间 vl：vl[汇] = ve[汇]，vl[i] = min(vl[j] - w(i,j))；
3. 对每条弧 <i,j> 算 e = ve[i]、l = vl[j] - w，e == l 的弧即关键活动，由关键活动连起来就是关键路径；
4. 邻接矩阵存储下，拓扑排序与 ve/vl 计算都是 O(n²)。

**易错点：** 把「关键路径」和「最短路径」混为一谈；ve 取 min、vl 取 max（方向全反）；只有一个汇点时忘了 vl 初始化应为 ve[汇]。
