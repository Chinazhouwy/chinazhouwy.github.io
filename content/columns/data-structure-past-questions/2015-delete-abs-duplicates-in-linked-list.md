# 2015 · 单链表删除绝对值重复的结点

> 卷面位置：2015 年综合卷 第 41 题（15 分）、第 42 题（8 分）。第 42 题的图以卷面为准。

## 第 41 题（15 分）：保留第一次出现的结点

给定一个带头结点的单链表，用 `data | link` 存储，请设计一个空间复杂度为 O(1) 的算法（注：若按题面允许辅助数组，则按题面约束作答），删除链表中绝对值相等的结点，即只保留第一次出现的结点。要求：给出算法的基本设计思想；用 C/C++ 描述算法并注释；说明时间复杂度。

## 考点

- 「绝对值相等」而不是「值相等」，需要取 |data|；
- 题面给出 |data| ≤ n，这个约束是允许 O(n) 辅助空间的钥匙；
- 链表中删除结点要维护前驱。

## 思路

因为 |data| ≤ n，开一个长度 n+1 的标记数组 `seen[]` 初值 0。从头遍历：

- 若 `seen[|p->data|] == 0`，标记为 1，保留该结点，pre 前移；
- 否则该结点是重复出现的绝对值，执行 `pre->next = p->next; free(p);`，p 指向下一个结点。

时间复杂度 O(n)，空间 O(n)。若题目硬性要求 O(1) 空间，只能对每个结点向前扫描已有结点做比较，时间退化为 O(n²)——两种写法都要能说清取舍。

## 参考实现（C）

```c
typedef struct LNode {
    int data;
    struct LNode *link;
} LNode, *LinkList;

void deleteAbsDuplicates(LinkList head, int n) {
    int *seen = (int *)calloc(n + 1, sizeof(int));   /* |data| <= n */
    LNode *pre = head, *p = head->link;
    while (p != NULL) {
        int v = p->data < 0 ? -p->data : p->data;
        if (!seen[v]) {
            seen[v] = 1;
            pre = p;
            p = p->link;
        } else {
            pre->link = p->link;
            free(p);
            p = pre->link;
        }
    }
    free(seen);
}
```

## 复杂度

- 时间：O(n)，一趟遍历；
- 空间：O(n)，标记数组（若按 O(1) 空间要求，则 O(n²) 时间、O(1) 空间）。

## 容易丢分的地方

- 忘记取绝对值，把 -5 和 5 当成不同结点；
- 删除时 p 直接后移但 pre 没跟，链表断裂；
- 标记数组下标用 data 本身（负数下标越界）；
- 用 `free(p)` 后还访问 p->link。

## 第 42 题（8 分）：邻接矩阵与图的基本性质

题面给出一个有向图（或网）的邻接矩阵与顶点集，要求写出（或补全）该图的邻接矩阵；说明矩阵中 A[i][j] 的含义与取值的含义；回答以下问题并说明理由。

- 一个 n 个顶点的有向图，其邻接矩阵是 n×n 的方阵，A[i][j] ≠ 0 表示存在弧 <i, j>；无权图中取值 1，网中取值即权值（∞ 表示无弧，自身为 0）。
- 邻接矩阵的对角线一般不参与判断连通性；第 i 行非零元个数 = 顶点 i 的出度，第 j 列非零元个数 = 入度；
- 无向图的邻接矩阵一定对称，有向图不一定；无向图矩阵中非零元总数 = 2e。

**容易丢分的地方：** 把行当作入度、列当作出度（正好反了）；把 ∞ 当成 0 处理导致「到处都是边」；忘记说明矩阵对稀疏图浪费空间、空间复杂度 O(n²)。具体顶点与权值以卷面图为准，本题的得分点在「按图填矩阵 + 会读出度/入度」。
