# 2020 · 三元组的最小距离与前缀编码

> 卷面位置：2020 年综合卷 第 41 题（13 分）、第 42 题（10 分）。

## 第 41 题（13 分）：最小距离

定义三元组 (a, b, c)（a、b、c 均为正数）的距离 D = |a - b| + |b - c| + |c - a|。给定 3 个非空整数集合 S₁、S₂、S₃，按升序分别存储在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能的三元组 (a, b, c)（a∈S₁，b∈S₂，c∈S₃）中的最小距离。例如 S₁ = {-1, 0, 9}，S₂ = {-25, -10, 10, 11}，S₃ = {2, 9, 17, 30, 41}，则最小距离为 2，相应的三元组为 (9, 10, 9)。要求：给出算法的基本设计思想；用 C/C++ 描述算法并注释；说明时间复杂度与空间复杂度。

## 考点

- D 只由三个数中的最大值与最小值决定：D = 2 × (max - min)，中间那个数不影响距离；
- 所以目标是让三数尽量靠近：每轮把「当前最小的那个数」所在数组的指针向前推；
- 暴力三重循环是 O(n³)，三指针是 O(n₁ + n₂ + n₃)。

## 思路

i = j = k = 0。循环：

1. 计算当前 D；
2. 更新最小值；
3. 把 a、b、c 中最小的那个指针 +1（它已无法再改善——因为其他两个都 ≥ 它，继续减小它只会拉大极差）；
4. 任一指针越界即结束。

## 参考实现（C）

```c
int minDistance(int A[], int la, int B[], int lb, int C[], int lc) {
    int i = 0, j = 0, k = 0, best = INT_MAX;
    while (i < la && j < lb && k < lc) {
        int d = abs(A[i] - B[j]) + abs(B[j] - C[k]) + abs(C[k] - A[i]);
        if (d < best) best = d;
        /* 推进最小的那个指针 */
        if (A[i] <= B[j] && A[i] <= C[k]) i++;
        else if (B[j] <= A[i] && B[j] <= C[k]) j++;
        else k++;
    }
    return best;
}
```

## 复杂度

- 时间：O(la + lb + lc)，每轮至少推进一个指针；
- 空间：O(1)。

## 容易丢分的地方

- 只推进 i、j、k 中的一个固定指针，漏解；
- 用三重循环 O(n³)，效率分全扣；
- D 写成 |a-b|+|b-c| 漏掉 |c-a|；
- 三个指针相等时只推进一个，平白多跑几轮（不影响正确性，但答题时最好说明「任选一个」）。

## 第 42 题（10 分）：前缀编码

题面给出若干由 0/1 组成的码字，要求：说明如何把它们组织成一棵二叉树（或说明字典树的构造）；给出类型定义并描述译码算法（给定 0/1 序列，输出对应的字符序列）；若给定一组新的编码，设计算法判断它是否为前缀编码。

## 考点

- 前缀编码的本质：任一码字都不是另一个码字的前缀；
- 二叉树中「码字」对应叶结点，左 0 右 1；
- 判定前缀性最直接的是建 Trie：若某个码字结束的结点还有孩子，或者码字路径上经过别的码字结束点，就不满足。

## 思路

**存储：** 二叉树/字典树结点 `left, right, isEnd, ch`。插入码字时逐位下行，走到底把 `isEnd = 1` 并记下字符。

**译码：** 从根出发，遇到 0 走左、1 走右，走到 `isEnd` 结点就输出该字符并回到根，继续读下一位。读到结束但不在叶结点 → 输入非法。

**判定前缀编码：** 插入全部码字后，检查每个 `isEnd` 结点是否还有子结点（有 → 某码字是别的码字前缀，不是前缀编码）；另外插入过程中若经过一个 `isEnd` 结点，也说明冲突。

## 参考实现（C，判定前缀编码）

```c
#define MAXN 1000
int ch[MAXN * 8][2];      /* 字典树：两个孩子下标，0 表示不存在 */
int isEnd[MAXN * 8];
int tot = 1;              /* 0 号为根 */

/* 返回 1 表示是前缀编码；失败返回 0 */
int insertCode(const char *code) {
    int p = 0;
    for (int i = 0; code[i]; i++) {
        int c = code[i] - '0';
        if (isEnd[p]) return 0;              /* 经过别的码字结尾 */
        if (!ch[p][c]) ch[p][c] = tot++;
        p = ch[p][c];
    }
    if (isEnd[p]) return 0;                  /* 码字重复 */
    if (ch[p][0] || ch[p][1]) return 0;      /* 本码字是别的码字前缀 */
    isEnd[p] = 1;
    return 1;
}
```

## 复杂度

- 建树：O(码字总长度)；
- 译码：O(码文总长度)；
- 空间：O(码字总长度)。

## 容易丢分的地方

- 判定时只看「是否有孩子」，漏掉「码字重复」和「经过别的码字结尾」；
- 把前缀编码和哈夫曼编码混为一谈（哈夫曼编码一定是前缀编码，但前缀编码不必来自哈夫曼树）；
- 译码时走到叶结点忘记回到根，后续全错。
