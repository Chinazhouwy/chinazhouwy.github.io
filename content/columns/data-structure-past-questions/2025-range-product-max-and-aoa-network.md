# 2025 · 区间乘积最大值与 AOE 网关键活动

> 卷面位置：2025 年综合卷 第 41 题（13 分）、第 42 题（10 分）。第 42 题的 AOE 网以卷面题 42 图为准。

## 第 41 题（13 分）：calMulMax

设有两个长度均为 n 的一维整型数组 A 和 res，对数组 A 中的每个元素 A[i]，计算 A[i] 与 A[j]（0 ≤ i ≤ j ≤ n-1）乘积的最大值，并将其保存到 res[i] 中。例如 A = {1, 4, -9, 6}，则得到 res = {6, 24, 81, 36}。现给定数组 A，请设计一个时间和空间上尽可能高效的算法 `void calMulMax(int A[], int res[], int n)`，求 res 中各元素的值。要求：给出算法的基本设计思想（4 分）；用 C/C++ 描述算法，关键之处给出注释（7 分）；说明时间复杂度和空间复杂度（2 分）。

## 考点

- 暴力 O(n²) 是最容易想到的，但不是「尽可能高效」；
- 负负得正：A[i] 为负时要乘后缀最小值，A[i] 为正时要乘后缀最大值；
- 从右往左扫，一趟同时维护后缀最大值 maxSuf 与后缀最小值 minSuf。

## 思路

令 `maxSuf[i] = max(A[i..n-1])`、`minSuf[i] = min(A[i..n-1])`。则：

```text
res[i] = max(A[i] * maxSuf[i], A[i] * minSuf[i])
```

因为 j 取 i..n-1，A[j] 的极值只可能是后缀最大或后缀最小，其余取值都不可能产生更大的乘积。倒序遍历时这两个后缀极值可以在 O(1) 内滚动更新，不必另开数组。

以 A = {1, 4, -9, 6} 验证：
- i=3：A[3]=6，后缀只有 6 → 36；
- i=2：A[2]=-9，后缀 {−9, 6}，max=6、min=−9 → max(−54, 81) = 81；
- i=1：A[1]=4，后缀 {4,−9,6}，max=6、min=−9 → max(24, −36) = 24；
- i=0：A[0]=1，后缀 max=6、min=−9 → max(6, −9) = 6。

结果 {6, 24, 81, 36}，与题面一致。

## 参考实现（C）

```c
void calMulMax(int A[], int res[], int n) {
    int maxSuf = A[n - 1], minSuf = A[n - 1];
    for (int i = n - 1; i >= 0; i--) {
        /* 用当前元素更新后缀极值（保证 j 可以取到 i 本身） */
        if (A[i] > maxSuf) maxSuf = A[i];
        if (A[i] < minSuf) minSuf = A[i];
        int p1 = A[i] * maxSuf;
        int p2 = A[i] * minSuf;
        res[i] = p1 > p2 ? p1 : p2;
    }
}
```

## 复杂度

- 时间：O(n)，一趟倒序扫描；
- 空间：O(1)，只用了两个滚动变量。

## 容易丢分的地方

- 只维护后缀最大值，负数元素处结果错（本例 res[2] 会算成 −54）；
- 顺序遍历却想用「后缀」极值，逻辑不成立；
- 以为 j 必须大于 i，漏掉 j = i（A[i] 自乘）；
- 用 `int` 存储乘积但数据范围含 10⁵ 级元素时溢出，答题时应说明用 long long。

## 第 42 题（10 分）：AOE 网的最短工期与关键活动

某工程包含 12 个活动，用 AOE 网描述，各边标注活动及其持续时间。请回答：完成该工程的最短时间是多少？哪些活动是关键活动？若按最短时间完成工程，与活动 e 同时进行的活动可能有哪些？

**第 1、2 问（最短时间与关键活动）。**

1. 拓扑排序求事件最早发生时间：ve[源] = 0，ve[j] = max(ve[i] + w(i,j))；
2. 逆拓扑序求事件最晚发生时间：vl[汇] = ve[汇]，vl[i] = min(vl[j] − w(i,j))；
3. 对每条弧 <i,j>：活动最早开始 e(i,j) = ve[i]，最晚开始 l(i,j) = vl[j] − w(i,j)；
4. **e == l 的活动即关键活动**，它们连成的路径是关键路径，其长度就是最短工期（即 ve[汇]）。

**第 3 问（与活动 e 同时进行的活动）。** 判据是「时间区间可能重叠」：活动 e 的执行窗口是 [ve[e 起点], vl[e 终点]]，另一个活动 x 若存在时间重叠的可能，就算可与 e 同时进行。答题时要给出每个候选活动的 e、l 值与持续期，指出其可执行区间与 e 的区间相交，再逐个列出；不能只凭图上相邻就下结论。

## 复杂度

- 邻接表存储：拓扑排序 + ve/vl 计算 O(n + e)；
- 邻接矩阵存储：O(n²)。

## 容易丢分的地方

- 把 ve 和 vl 的取 max / min 弄反；
- 关键路径只写一条，忽略「可能有多条关键路径」（12 个活动的网常见多解）；
- 「同时进行」按图上位置邻近判断，没算时间窗口；
- 最短时间答成边数之和或最长边的长度。
