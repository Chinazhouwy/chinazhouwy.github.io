# 2021 · 欧拉路径判定与比较计数排序

> 卷面位置：2021 年综合卷 第 41 题（15 分）、第 42 题（8 分）。

## 第 41 题（15 分）：IsExistEL

已知无向连通图 G 由顶点集 V 和边集 E 组成，|E| > 0。当 G 中不存在度为奇数的顶点（即全部顶点度数为偶）时，G 中存在欧拉回路；当 G 中恰有 2 个顶点度为奇数时，既存在一条从其中一个奇度顶点出发、到另一个奇度顶点结束的欧拉路径，也存在欧拉回路（题面按此设定）。G 的邻接矩阵为 `M`，`M[i][j] = 1` 表示存在边，为 0 表示无边。现要设计算法判断 G 中是否存在欧拉路径，函数原型为 `int IsExistEL(MGraph G)`，若存在返回 1，否则返回 0。要求：给出算法的基本设计思想；用 C/C++ 描述算法并注释；说明时间复杂度与空间复杂度。

## 考点

- 欧拉路径存在的充要条件：连通 + 奇度顶点数为 0 或 2；
- 邻接矩阵中第 i 行非零元个数即顶点 i 的度（无向图）；
- 只需统计奇度顶点个数，不需要真的找路径。

## 思路

遍历 `M` 的每一行，统计该行非零元个数（自环按题面约定处理，若矩阵对称则行和即度）。记录度数为奇数的顶点个数 odd。最后 `return (odd == 0 || odd == 2);`。题目给的 G 已连通，因此不必再做连通性判定；若题面未给连通前提，则要先 DFS/BFS 判连通，再按点数判奇度。

## 参考实现（C）

```c
#define MAXV 100
typedef struct {
    int numVertices, numEdges;
    char VerticesList[MAXV];
    int Edge[MAXV][MAXV];
} MGraph;

int IsExistEL(MGraph G) {
    int odd = 0;
    for (int i = 0; i < G.numVertices; i++) {
        int deg = 0;
        for (int j = 0; j < G.numVertices; j++)
            if (G.Edge[i][j] != 0) deg++;
        if (deg % 2 == 1) odd++;
    }
    return (odd == 0 || odd == 2) ? 1 : 0;
}
```

## 复杂度

- 时间：O(n²)，遍历整个邻接矩阵；
- 空间：O(1)，只用常数个辅助变量。

## 容易丢分的地方

- 写成统计边数、判断边数与顶点数的关系；
- 奇度顶点个数判断写成 `odd == 2`，漏掉全偶（欧拉回路）也算存在路径；
- 邻接矩阵按无向图对称存储时把每条边数了两次，导致度翻倍（偶奇性不变，但答题要交代）；
- 忘记题面「|E| > 0」的前提，空图不该返回 1。

## 第 42 题（8 分）：比较计数排序 cmpCountSort

题面给出一段按「与其余元素逐个比较并计数」实现排序的算法（元素存于 `a[0..n-1]`，用 `count[i]` 记录比 a[i] 小的元素个数，最后按 count 放入 `b[]`）。要求：

1. 对输入 `a = {25, -10, 25, 10, 11, 19}`，写出算法的输出（即 `b[]`）；
2. 说明该算法共执行了多少次元素比较；
3. 该算法是否稳定？若不是，如何修改才能稳定？

**第 1 问：** 升序结果为 `b = {-10, 10, 11, 19, 25, 25}`。

**第 2 问：** 每个 i 与所有 j > i 比较一次，比较次数 = n(n-1)/2 = 6×5/2 = **15** 次。

**第 3 问：** 原算法**不稳定**。它的判定是 `if (a[i] < a[j]) count[j]++; else count[i]++;`，两个元素相等时会走 else 分支，让后面那个（j）拿到更小的名次，相等元素的相对次序被打乱。

修法：把相等的情形归到「后者名次 +1」，即改成

```c
if (a[i] <= a[j]) count[j]++;
else count[i]++;
```

这样相等元素中原本靠前的仍排在前面，算法变成稳定排序。

## 复杂度

- 时间：O(n²)，双重循环；
- 空间：O(n)，count 与 b 数组。

## 容易丢分的地方

- 比较次数算成 n² 或 n(n+1)/2；
- 稳定性只看「相等元素值相同」就断言稳定，没有检查 else 分支的归属；
- 修改后没有说清「为什么这样就稳定」——要点是「相等时保留原相对次序」。
