# 2023 · 出度大于入度的顶点与置换-选择排序

> 卷面位置：2023 年综合卷 第 41 题（13 分）、第 42 题（10 分）。

## 第 41 题（13 分）：printVertices

已知有向图 G 采用邻接矩阵存储，类型定义包含顶点数 `numVertices`、边数 `numEdges`、顶点表 `VerticesList[]` 与邻接矩阵 `Edge[][]`。将图中出度大于入度的顶点称为「出度大于入度的顶点」（题面定义），函数原型为 `int printVertices(MGraph G)`：对任意给定的非空有向图 G，输出图 G 中所有出度大于入度的顶点，并返回这类顶点的个数。

## 考点

- 有向图邻接矩阵：第 i 行非零元个数 = 顶点 i 的出度，第 j 列非零元个数 = 顶点 j 的入度；
- 一次两重循环同时累加行和与列和，避免重复遍历；
- 边数 `numEdges` 只在需要校验时用。

## 思路

遍历矩阵每个元素 `Edge[i][j]`：非零则 `outdeg[i]++`、`indeg[j]++`。随后对每个顶点比较 `outdeg[i] > indeg[i]`，成立则输出顶点名、计数加一。返回计数。

## 参考实现（C）

```c
int printVertices(MGraph G) {
    int outdeg[MAXV] = {0}, indeg[MAXV];
    for (int i = 0; i < G.numVertices; i++) indeg[i] = 0;

    for (int i = 0; i < G.numVertices; i++)
        for (int j = 0; j < G.numVertices; j++)
            if (G.Edge[i][j] != 0) { outdeg[i]++; indeg[j]++; }

    int cnt = 0;
    for (int i = 0; i < G.numVertices; i++)
        if (outdeg[i] > indeg[i]) {
            printf("%c ", G.VerticesList[i]);
            cnt++;
        }
    return cnt;
}
```

## 复杂度

- 时间：O(n²)，一趟矩阵扫描；
- 空间：O(n)，出度与入度数组。

## 容易丢分的地方

- 行列搞反（行当入度、列当出度）；
- 只算出度，入度另起一次循环却忘记清零累加器，导致重复计；
- 把「出度大于入度」误读成「出度最大」；
- 返回的是顶点个数，不是边数。

## 第 42 题（10 分）：置换-选择排序与初始归并段

对含 n（n > 0）个记录的文件做外部排序，采用置换-选择排序生成初始归并段，工作区可容纳 m 个记录。若文件中有 19 个记录，关键字依次为：

```text
51, 94, 37, 92, 14, 63, 15, 99, 48, 56, 23, 60, 31, 17, 43, 8, 90, 166, 100
```

m = 4 时可生成几个初始归并段？每个归并段各是什么？对任意 m（n > m > 0），第一个初始归并段的长度最大值和最小值分别是多少？

## 考点

- 置换-选择排序的核心规则：输出当前工作区中「不小于上一个输出值」的最小记录；比它小的记录被冻结，留给下一段；
- 一段结束时解冻全部冻结记录，重新开始；
- 段长与初始数据的「有序性」直接相关：数据越有序，段越长。

## 推演（m = 4）

**第一段：** 装入 51, 94, 37, 92。

| 输出 | 带入的下一个记录 | 状态 |
|---|---|---|
| 37 | 14（< 37，冻结） | 51, 92, 94 可用 |
| 51 | 63（≥ 51，可用） | 92, 94, 63 |
| 63 | 15（< 63，冻结） | 92, 94, 15f |
| 92 | 99（可用） | 94, 99, 15f |
| 94 | 48（< 94，冻结） | 99, 15f, 48f |
| 99 | 56（冻结） | 全部冻结，段结束 |

第一段 = (37, 51, 63, 92, 94, 99)，长度 6。

**第二段：** 解冻 14, 15, 48, 56。

依次输出 14 → 15 → 23 → 31 → 48 → 56 → 60 → 90 → 166，其间带入的 17、43、8、100 因小于当时的输出值被冻结。

第二段 = (14, 15, 23, 31, 48, 56, 60, 90, 166)，长度 9。

**第三段：** 解冻 17, 43, 8, 100，输出 8 → 17 → 43 → 100，记录已读完。

第三段 = (8, 17, 43, 100)，长度 4。

**结论：共 3 个初始归并段**，长度 6、9、4，合计 19 个记录，与文件记录数一致（这一步自查很重要）。

**第 2 问：** 第一个初始归并段的长度最大值是 **n**（文件本身已按关键字有序时，全部记录能在一段内输出），最小值是 **m**（工作区装满后，新带入的每个记录都比上一个输出值小，输出完 m 个即冻结）。

## 复杂度

- 用败者树实现时每次选择 O(log m)，总时间 O(n log m)；
- 空间 O(m)。

## 容易丢分的地方

- 把「大于上一个输出值」写成「大于等于工作区最小值」，把可用的记录提前冻结；
- 冻结记录仍参与本轮选择，导致段内无序；
- 段尾忘记解冻，直接结束算法；
- 段长最大/最小答成「m 和 1」——最小值不能小于 m，因为装满工作区才能产出第一段。
