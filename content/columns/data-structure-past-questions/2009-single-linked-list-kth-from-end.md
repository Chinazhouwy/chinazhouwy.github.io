# 2009 · 单链表倒数第 k 个结点

> 卷面位置：2009 年综合卷 第 41 题（10 分）与 第 42 题（15 分）。题干按卷面整理，非逐字影印；原卷为扫描件，个别符号以题意为准。

## 第 42 题（15 分）：单链表倒数第 k 个结点

已知一个带有表头结点的单链表，结点结构为 `data | link`。假设该链表只给出了头指针 `list`。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第 k 个位置上的结点（k 为正整数）。若查找成功，算法输出该结点的 data 域的值，并返回 1；否则只返回 0。要求：

1. 描述算法的基本设计思想；
2. 描述算法的详细实现步骤；
3. 根据设计思想和实现步骤，采用程序设计语言描述算法（使用 C、C++ 或 Java），关键之处给出注释。

## 考点

- 单链表只能单向遍历，无法反向计数；
- 一趟扫描内构造「固定间距」的双指针；
- 边界：k 大于表长、k = 1、空表、只有头结点。

## 思路

设两个指针 p、q 起初都指向首元结点。先让 p 沿链表走 k 步：

- 若 p 在走满 k 步之前就变成 NULL，说明表长不足 k，返回 0；
- 否则让 p、q 同步后移，直到 p 变成 NULL。此时 p 比 q 领先 k 个结点，q 正好落在倒数第 k 个结点上。

关键在于「先拉开 k 个身位，再一起走」，这样只扫描一趟，也不需要预先求表长。

## 参考实现（C）

```c
typedef struct LNode {
    int data;
    struct LNode *link;
} LNode, *LinkList;

int findKthFromEnd(LinkList list, int k) {
    if (list == NULL || k <= 0) return 0;
    LNode *p = list->link;      /* 首元结点 */
    LNode *q = list->link;
    if (p == NULL) return 0;    /* 空表 */

    for (int i = 0; i < k; i++) {
        if (p == NULL) return 0;   /* 表长不足 k */
        p = p->link;
    }
    while (p != NULL) {            /* p、q 同步后移 */
        p = p->link;
        q = q->link;
    }
    printf("%d\n", q->data);
    return 1;
}
```

## 复杂度

- 时间：O(n)，最多遍历一趟半（先 k 步，再 n-k 步）；
- 空间：O(1)，只用了两个指针。

## 容易丢分的地方

- 把「带表头结点」当成首元结点，导致整体错位一个结点；
- k 大于表长时仍然访问 q->data，越界；
- 先求表长再走 n-k 步——正确但被题目要求的高效性扣分，且多扫一趟；
- 忘记返回 0/1 的约定。

## 第 41 题（10 分）：最短路径贪心为什么不行

题目给出一段「从初始顶点出发，每次选离当前顶点最近且尚未加入路径的顶点，把当前顶点改为它，重复直到目标顶点」的求解过程，要求：判断该过程能否求出带权图（权值非负）的最短路径；若可以，说明理由，否则举反例；再讨论它与迪杰斯特拉算法的差别。

**结论：不能。** 这个过程的致命缺陷是只用「当前顶点到下一个顶点的一步距离」，从不保留「起点到这个顶点的最短距离」，因此可能提前拐进一条看起来近、实际绕远的路。

反例（四个顶点，求 v0 到 v3 的最短路径）：

```text
v0 -2- v1
v0 -3- v2
v1 -2- v2
v2 -1- v3
```

- 该过程：v0 → 选最近的 v1（2）→ 从 v1 选最近的 v2（2）→ v2 → v3（1），总长 5；
- 真正最短：v0 → v2（3）→ v3（1），总长 4。

迪杰斯特拉的关键区别是维护 dist 数组：每加入一个顶点就对其邻接点做松弛，并允许修改已定下的候选距离；上面那个过程既没有 dist，也没有松弛，所以只是最近邻贪心。
