# 2010 · 数组循环左移 p 位

> 卷面位置：2010 年综合卷 第 41 题（10 分）与 第 42 题（13 分）。

## 第 42 题（13 分）：循环左移

设将 n（n>1）个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p 个位置（0<p<n），即把 R 中的数据序列由 (x0, x1, …, xn-1) 变换为 (xp, xp+1, …, xn-1, x0, x1, …, xp-1)。要求：

1. 给出算法的基本设计思想；
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释；
3. 说明所设计算法的时间复杂度和空间复杂度。

## 考点

- 循环左移的本质是「两段互换位置」；
- 三次逆置把 O(n) 的搬移压到 O(1) 额外空间；
- 与「辅助数组整体拷贝」方案的空间复杂度对比。

## 思路

把数组看成两段：A = R[0..p-1]、B = R[p..n-1]，目标是 B A。做法：

1. 逆置 A，得到 A⁻¹B；
2. 逆置 B，得到 A⁻¹B⁻¹；
3. 整体逆置，(A⁻¹B⁻¹)⁻¹ = BA，完成。

## 参考实现（C）

```c
void reverse(int R[], int from, int to) {
    for (int i = 0; i < (to - from + 1) / 2; i++) {
        int tmp = R[from + i];
        R[from + i] = R[to - i];
        R[to - i] = tmp;
    }
}

void rotateLeft(int R[], int n, int p) {
    if (n <= 1 || p <= 0 || p >= n) return;
    reverse(R, 0, p - 1);      /* 逆置 A */
    reverse(R, p, n - 1);      /* 逆置 B */
    reverse(R, 0, n - 1);      /* 整体逆置 */
}
```

以 R = {1,2,3,4,5,6}、p = 3 验证：逆置前段 → {3,2,1,4,5,6}；逆置后段 → {3,2,1,6,5,4}；整体逆置 → {4,5,6,1,2,3}，正是循环左移 3 位。

## 复杂度

- 时间：O(n)，三次逆置合计约 2n 次交换；
- 空间：O(1)。

## 容易丢分的地方

- 逆置区间写成 `to - from` 而不是 `to - from + 1`，偶数长度时漏掉中间一对；
- p、n 边界不校验，p >= n 时数组错位；
- 用辅助数组 O(n) 空间，虽然结论正确但拿不到空间分。

## 第 41 题（10 分）：散列表的装填因子与查找长度

将关键字序列 7, 8, 30, 11, 18, 9, 14 依次存储到散列表中。散列函数 H(key) = (key × 3) mod 7，线性探测再散列处理冲突，装填因子 α = 0.7。要求：画出散列表；分别计算等概率情况下查找成功和查找失败的平均查找长度。

**表长与散列地址。** 装填因子 α = 记录数 / 表长，7/0.7 = 10，故表长为 10（下标 0..9）。

逐个插入：

| key | H(key) | 实际位置 | 探测次数 |
|---|---|---|---|
| 7 | 21 mod 7 = 0 | 0 | 1 |
| 8 | 24 mod 7 = 3 | 3 | 1 |
| 30 | 90 mod 7 = 6 | 6 | 1 |
| 11 | 33 mod 7 = 5 | 5 | 1 |
| 18 | 54 mod 7 = 5 → 6 占用 | 7 | 3 |
| 9 | 27 mod 7 = 6 → 7 占用 → 8 空 | 8 | 3 |
| 14 | 42 mod 7 = 0 → 1 空 | 1 | 2 |

散列表：`0:7, 1:14, 2:空, 3:8, 4:空, 5:11, 6:30, 7:18, 8:9, 9:空`。

- 查找成功 ASL = (1+1+1+1+3+3+2)/7 = 13/7 ≈ 1.86；
- 查找失败 ASL 按 H 的可能取值 0..6 分别算到「第一个空单元」的探测次数：H=0 → 3（0,1,2），H=1 → 2（1,2），H=2 → 1，H=3 → 2（3,4），H=4 → 1，H=5 → 5（5,6,7,8,9），H=6 → 4（6,7,8,9），合计 18，ASL 失败 = 18/7 ≈ 2.57。

失败分支数等于散列函数的值域（这里是 7），不是表长，这一点最容易错。
