# 2026 · 二叉搜索树找最接近 k 的结点与出栈序列

> 卷面位置：2026 年综合卷 第 41 题、第 42 题（10 分）。题干按卷面整理，非逐字影印。

## 第 41 题：searchX

已知二叉搜索树采用二叉链表存储，结点含 `data`、`left`、`right`，`root` 为根指针。对给定的非空二叉搜索树 T 和整数 k，请设计尽可能高效的查找算法 `void searchX(BTree root, int k)`，查找 T 中「关键字值与 k 之差的绝对值最小」的**所有**结点，输出差值以及这些结点的关键字值。要求：给出算法的基本设计思想；用 C/C++ 描述算法，关键之处给出注释。

## 考点

- 二叉搜索树中序序列有序，这是「高效」的立足点；
- 要找的是「所有」差值最小的结点（可能有两个：k 左右各一个），不能找到第一个就返回；
- 先定位 k 应插入的位置，再向两侧扩展，是这个题的标准解法。
- 注意差值的绝对值可能出现 1 个或 2 个最小值（如果左右对称），必须都输出。

## 思路

1. 沿 BST 查找路径找「最接近 k」的结点 best，记录最小差值 d = |best->data − k|；
2. 再沿查找路径回溯，检查每个结点另一侧子树中是否有差值同为 d 的结点：BST 中若要找与 k 差值恰好为 d 的另一个值，只可能是 k − d 或 k + d，直接在树上用普通查找找这两个值是否存在即可；
3. 输出 d 及所有命中的关键字值。

更直观的写法：中序遍历整棵树，边遍历边维护最小差值与其结点集合；遇到更小差值就清空集合、遇到相等差值就追加。时间 O(n)，代码短、不容易错，缺点是没用上 BST 的 O(log n) 定位优势。评分上「思路 + 复杂度」都说清楚即可。

## 参考实现（C，中序遍历版）

```c
typedef struct BSTNode {
    int data;
    struct BSTNode *left, *right;
} BSTNode, *BTree;

static int minDiff;
static int found[64], foundCnt;

static void inorder(BTree t, int k) {
    if (t == NULL) return;
    inorder(t->left, k);
    int d = t->data - k;
    if (d < 0) d = -d;
    if (d < minDiff) { minDiff = d; foundCnt = 0; found[foundCnt++] = t->data; }
    else if (d == minDiff && foundCnt < 64) found[foundCnt++] = t->data;
    inorder(t->right, k);
}

void searchX(BTree root, int k) {
    minDiff = 0x7fffffff;
    foundCnt = 0;
    inorder(root, k);
    for (int i = 0; i < foundCnt; i++)
        printf("差值 %d，关键字 %d\n", minDiff, found[i]);
}
```

**想拿满效率分的写法：** 先按 BST 查找走到「最近结点」确定 minDiff，再用 `search(root, k - minDiff)`、`search(root, k + minDiff)` 各做一次 O(h) 查找，总时间 O(h)，h 为树高。

## 复杂度

- 中序版：时间 O(n)，空间 O(h)；
- 定位 + 两次查找版：时间 O(h) = O(log n)（平均），空间 O(1)。

## 容易丢分的地方

- 找到第一个最小值就返回，漏掉对称位置的另一个结点；
- 只比较路径上的结点，忘记检查另一侧子树里的候选；
- 差值用有符号数比较，负数时判断反了；
- 空树未处理。

## 第 42 题（10 分）：出栈序列

栈的基本操作有入栈和出栈。将序列 1, 2, 3, …, n 依次入栈，回答下列问题。

**(1) n = 9 时，能否得到出栈序列 {2, 3, 1, 6, 4, 7, 5, 9, 8}？能否得到 {2, 3, 1, 5, 6, 7, 4, 9, 8}？**

- 第一个序列：`2, 3, 1` 合法；接着要输出 6，需先把 4、5、6 入栈再弹出 6，此时栈内自顶向下是 5, 4（4 压在 5 下面），下一个要求输出的是 4，但栈顶是 5 → **不可能**。
- 第二个序列：`2, 3, 1` 合法；再依次入栈 4、5 弹出 5，入栈 6 弹出 6，入栈 7 弹出 7，随后弹出 4；再入栈 8、9 弹出 9、弹出 8 → **可以得到**。

**(2) 若出栈序列不能由栈得到，则 Pi、Pj、Pk（i < j < k）的大小关系是什么？**

答案是 **Pj < Pk < Pi**。

理由：若 Pi 比 Pk 大而 Pk 又比 Pj 大，说明 Pk 在 Pi 之后才出栈、却被 Pi「压住」，而 Pj 又比 Pk 更小、更早出栈——在这个位置上栈的「后进先出」被破坏。用第一个序列验证：取 i=4（值 6）、j=5（值 4）、k=7（值 5），正是 4 < 5 < 6，即 Pj < Pk < Pi，与结论一致。

**(3) n = 4 时，以 2 开头的出栈序列有多少个？**

出栈序列总数为卡特兰数 C₄ = 14（全列出为 1234、1243、1324、1342、1432、2134、2143、2314、2341、2431、3214、3241、3421、4321）。其中以 2 开头的有 **5 个**：2134、2143、2314、2341、2431。

**(4) 若 n = k−1 时出栈序列总共有 M 个，则 n = k 时：以 1 开头有多少个？以 2 开头有多少个？总共有多少个？**

- 以 1 开头：先把 1 入栈并立即弹出，剩下 k−1 个元素的入栈出栈完全自由 → **M 个**；
- 以 2 开头：必须先把 1、2 入栈再弹出 2，此时 1 在栈顶、结构上等价于 k−1 个元素的情形 → **M 个**；
- 总共：卡特兰数 **C_k = (2k)! / (k!(k+1)!)**，也可写成 `M × 2(2k−1)/(k+1)`。用 k=4 验证：M = C₃ = 5，5 × 2×7/5 = 14 = C₄ ✓。

## 复杂度 / 判定算法要点

判断一个给定序列能否由栈得到，用模拟法 O(n)：维护一个栈，按 1..n 依次入栈，每次入栈后检查栈顶是否等于序列当前要输出的值，是就连续弹出，最后栈空即合法。

## 容易丢分的地方

- 第 2 问把大小关系写成 Pi < Pj < Pk（这只是「值递增」，与栈无关）；
- 第 3 问忘记总数为 14，凭感觉给个数；
- 第 4 问「以 2 开头」未经论证直接等于 M；
- 判合法时只检查相邻两个元素的大小关系，不用栈模拟。
