## 0. 这一篇解决什么问题

## 1. 网页运行原理与职业认知

### 1.1 计算机与软件

- 计算机 = **硬件**（看得见摸得着的物理部件）+ **软件**（指挥硬件工作的指令）
- 软件分类：**系统软件**（Windows、Linux、Android、HarmonyOS）与**应用软件**（微信、QQ、Photoshop）

### 1.2 C/S 架构 vs B/S 架构

| | C/S 架构 | B/S 架构 |
|---|---|---|
| 全称 | Client（客户端）/ Server（服务器） | Browser（浏览器）/ Server（服务器） |
| 特点 | 需要安装、偶尔更新、不跨平台、开发更具针对性 | 无需安装、无需更新、可跨平台、开发更具通用性 |

- 服务器：为软件提供数据的设备
- 前端工程师主要负责编写 B/S 架构中的网页（呈现界面 + 实现交互）
- 大前端时代：前端技术栈也能做出 C/S 应用、甚至搭建服务器

### 1.3 浏览器与内核

五大浏览器：Chrome（谷歌）、Safari、IE、Firefox（火狐）、Opera（欧朋）。

常见内核：Blink（Chrome/Edge/Opera）、WebKit（Safari）、Gecko（Firefox）。国产浏览器（360、QQ 等）多为 Chromium 内核 + IE 兼容模式双核。

### 1.4 网页标准

网页由三部分组成：

| 部分 | 语言 | 职责 |
|---|---|---|
| 结构 | HTML | 网页的内容和骨架 |
| 表现 | CSS | 网页的样式和布局 |
| 行为 | JavaScript | 网页的交互逻辑 |

## 2. HTML 是什么

全称 **HyperText Markup Language（超文本标记语言）**：超文本（内容比普通文本丰富）+ 标记（各种标记符号）+ 语言（标记的写法与规则）。

三个标准组织（了解）：

| 组织 | 全称 | 成立 | 职责 |
|---|---|---|---|
| IETF | Internet Engineering Task Force（国际互联网工程任务组） | 1985 | 互联网技术标准，绝大多数互联网技术标准出自这里 |
| W3C | World Wide Web Consortium（万维网联盟） | 1994 | Web 技术领域最具影响力的标准机构 |
| WHATWG | Web Hypertext Application Technology Working Group（网页超文本应用技术工作小组） | 2004 | 由 Opera、Mozilla、苹果等浏览器厂商组成，推动 HTML5 标准（原 PDF 误写为 WHATWF） |

发展史：HTML 1.0 → 2.0 → 3.2 → 4.01 → 5。目前最新标准是 **HTML 5**（现行规范以 WHATWG 的 HTML Living Standard 为准）。

## 3. 第一个 HTML 页面

### 3.1 标签与属性

- 标签又称**元素**，是 HTML 的基本组成单位，分**双标签**（`<p></p>`）和**单标签**（`<input>`），绝大多数是双标签
- 标签名不区分大小写，推荐小写
- 属性写在起始标签或单标签中，给标签提供附加信息
- 属性形式：`属性名="属性值"`；有些特殊属性只有属性名没有属性值（布尔属性，如 `<input disabled>`）
- 属性名/值不区分大小写，推荐小写；推荐写双引号（单引号、不写也能解析）
- 同名属性不要出现两次，后写的会失效（`<input type="text" type="password">` 中 type 为 password）

```html
<!-- 标签初体验：marquee 已废弃，仅用于演示（现用 CSS 动画替代） -->
<marquee loop="1" bgcolor="orange">尚硅谷，让天下没有难学的技术！</marquee>

<!-- 双标签 + 属性 + 布尔属性 -->
<p title="提示文字">普通段落</p>
<input type="password" disabled>

<!-- 标签关系：并列、嵌套（用 tab 缩进） -->
<ul>
  <li>嵌套的列表项</li>
</ul>
```

### 3.2 标准结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <title>我是一个标题</title>
    </head>
    <body>
        <!-- 想呈现在网页中的内容都写在 body 中 -->
    </body>
</html>
```

要点：
- `<!DOCTYPE html>` 文档声明必须写在**第一行、html 标签外侧**，告诉浏览器当前网页版本（HTML5 写法只有这一种，其他旧写法不用背）
- head 中的内容不会出现在网页中；title 指定网页标题
- VSCode 中输入 `!` 回车可快速生成标准结构；根目录放 `favicon.ico` 可配置网站图标

### 3.3 注释、字符编码、语言

```html
<!-- 注释：浏览器忽略，不呈现到页面，但源代码中可见；注释不能嵌套 -->
<!DOCTYPE html>
<html lang="zh-CN">  <!-- lang 作用：翻译提示 + SEO -->
<head>
    <meta charset="UTF-8">
</head>
</html>
```

**字符编码**（存储时编码、读取时解码，必须一致否则乱码）：

| 字符集 | 说明 |
|---|---|
| ASCII | 大小写字母、数字、符号，共 128 个 |
| ISO 8859-1 | ASCII 基础上扩充希腊字符等，256 个 |
| GB2312 | 收录 6763 个常用汉字、682 个字符 |
| GBK | 汉字和符号 20000+，支持繁体 |
| UTF-8 | 包含世界上所有语言的文字与符号，**统一使用它最稳妥** |

**lang 属性**：推荐 BCP 47 语言标签写法，如 `zh-CN`（简体中文）、`zh-TW`（繁体中文）、`en-US`（英语美国）、`en-GB`（英语英国）；`zh-Hans`/`zh-Hant` 是语言+文字变体的合法写法（原 PDF 称其"已不推荐"，不准确，两者并存）。

## 4. 排版与文本标签

### 4.1 排版标签

| 标签 | 语义 | 单/双 |
|---|---|---|
| h1 ~ h6 | 标题（一级到六级） | 双 |
| p | 段落 | 双 |
| div | 无语义，整体布局容器（"包装袋"） | 双 |

注意：h1 最好只写一个；h1~h6 不能互相嵌套；p 里面不能写 h1~h6、p、div。

### 4.2 语义化

用特定标签表达特定含义。原则：**默认效果不重要（CSS 随便改），语义最重要**。
优势：代码结构清晰可读、有利于 SEO、方便设备解析（屏幕阅读器、盲人阅读器）。

### 4.3 块级元素与行内元素

| | 块级元素 | 行内元素 |
|---|---|---|
| 排列 | 独占一行，从上到下 | 不独占一行，从左到右 |
| 默认宽度 | 撑满父元素 | 由内容撑开 |
| 默认高度 | 由内容撑开 | 由内容撑开 |
| 设置宽高 | 可以 | 不可以 |

使用原则：块级元素中几乎什么都能写；行内元素中能写行内元素，不能写块级元素。

### 4.4 文本标签

**常用**：

| 标签 | 语义 |
|---|---|
| em | 要着重阅读的内容（斜体） |
| strong | 十分重要的内容（语气比 em 强，加粗） |
| span | 无语义，包裹短语的通用容器 |

**不常用**（了解）：

| 标签 | 语义 | 标签 | 语义 |
|---|---|---|---|
| cite | 作品标题（书、歌、电影等） | code | 一段代码 |
| dfn | 特殊术语/专有名词 | samp | 设备输出内容 |
| del / ins | 删除的文本 / 插入的文本 | kbd | 键盘文本 |
| sub / sup | 下标 / 上标 | abbr | 缩写（配 title 属性） |
| bdo | 更改文本方向（dir: ltr/rtl） | var | 变量（可与 code 配合） |
| small | 附属细则（版权、法律文本） | q / blockquote | 短引用 / 长引用 |
| b | 加粗（无语义） | i | 本意思想活动；现多用于字体图标 |
| u | 与正常内容有反差文本 | address | 地址信息（块级） |

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<p>这是一个段落，里面可以放
  <strong>重要内容</strong>、
  <em>着重内容</em>、
  <span>普通短语</span>。
  化学式 H<sub>2</sub>O，面积 m<sup>2</sup>，
  <del>删除线</del><ins>插入线</ins>，
  <abbr title="HyperText Markup Language">HTML</abbr>。
</p>
<div>div 是块级布局容器，div 是大包装袋，span 是小包装袋</div>
```

## 5. 图片 img

| 属性 | 说明 |
|---|---|
| src | 图片路径（必填） |
| alt | 图片描述：SEO 依据、图片加载失败时显示、盲人阅读器朗读 |
| width / height | 宽度/高度，单位像素（尽量不同时修改，避免比例失调） |

```html
<img src="./monster.jpg" alt="一只怪兽" width="200">
<img src="https://example.com/logo.png" alt="网站 logo">
```

**路径分类：**

| 类型 | 写法 | 示例 |
|---|---|---|
| 相对路径-同级 | ./ | `<img src="./怪兽.jpg">`（./ 可省略） |
| 相对路径-下一级 | / | `<img src="./a/喜羊羊.jpg">` |
| 相对路径-上一级 | ../ | `<img src="../奥特曼.jpg">` |
| 本地绝对路径 | 盘符开头 | `E:/a/b/c/奥特曼.jpg`（很少用，换设备就失效） |
| 网络绝对路径 | http(s) | `https://xxx.com/logo.png`（注意服务器防盗链） |

**常见图片格式：**

| 格式 | 特点 | 使用场景 |
|---|---|---|
| jpg/jpeg | 有损压缩、颜色丰富、体积小、不支持透明与动图 | 产品宣传图（网页最常见） |
| png | 无损、支持透明背景、体积略大 | logo、重要配图 |
| bmp | 不压缩、细节最多、体积极大 | 大型游戏素材（网页很少用） |
| gif | 仅 256 色、支持简单透明、支持动图 | 网页动态图 |
| webp | 谷歌推出，兼具以上优点、体积更小 | 网页图片首选（原 PDF 称"兼容性不太好"已过时，2026 年所有主流浏览器均支持） |
| base64 | 图片编码成文本，直接作为 src 值，不受文件位置影响 | 小图标、需随网页一起加载的图片 |

## 6. 超链接 a

| 属性 | 说明 |
|---|---|
| href | 跳转目标 |
| target | `_self` 本窗口打开（默认）/ `_blank` 新窗口打开 |
| id | 元素唯一标识，可做锚点目标 |
| download | 强制触发下载，属性值为下载文件名 |

注意：a 是行内元素，但可以包裹除自身外的任何元素；代码中多个空格/回车会被解析成一个空格。

```html
<!-- 1. 跳转页面 -->
<a href="https://www.jd.com/" target="_blank">去京东</a>
<a href="./10_HTML排版标签.html" target="_self">去看排版标签</a>

<!-- 2. 跳转文件/触发下载 -->
<a href="./resource/自拍.jpg">看自拍</a>
<a href="./resource/内部资源.zip">内部资源（浏览器打不开会自动下载）</a>
<a href="./resource/小电影.mp4" download="电影片段.mp4">强制下载</a>

<!-- 3. 锚点：第一步设锚点，第二步跳转 -->
<a name="test1"></a>                    <!-- 方式一：a + name（name 锚点已废弃，见勘误） -->
<h2 id="test2">我是一个位置</h2>          <!-- 方式二：任何标签 + id（推荐） -->
<a href="#test1">去 test1 锚点</a>
<a href="#">回到顶部</a>
<a href="demo.html#test1">去 demo.html 的 test1 锚点</a>
<a href="">刷新本页面</a>
<a href="javascript:alert(1);">执行一段 JS</a>

<!-- 4. 唤起指定应用 -->
<a href="tel:10010">电话联系</a>
<a href="mailto:10010@qq.com">邮件联系</a>
<a href="sms:10086">短信联系</a>
```

## 7. 列表

```html
<!-- 有序列表：有顺序或侧重顺序 -->
<h2>要把大象放冰箱总共分几步</h2>
<ol>
    <li>把冰箱门打开</li>
    <li>把大象放进去</li>
    <li>把冰箱门关上</li>
</ol>

<!-- 无序列表：无顺序或不侧重顺序 -->
<h2>我想去的几个城市</h2>
<ul>
    <li>成都</li>
    <li>上海</li>
    <li>西安</li>
</ul>

<!-- 列表嵌套：结构务必写完整（ul 里套 li，li 里再套 ul） -->
<ul>
    <li>成都</li>
    <li>上海
        <ul>
            <li>外滩</li>
            <li><a href="https://www.opg.cn/">东方明珠</a></li>
        </ul>
    </li>
</ul>

<!-- 自定义列表：术语名称 + 术语描述 -->
<dl>
    <dt>做好笔记</dt>
    <dd>笔记是我们以后复习的一个抓手</dd>
    <dd>笔记可以是电子版，也可以是纸质版</dd>
    <dt>多加练习</dt>
    <dd>只有敲出来的代码，才是自己的</dd>
</dl>
```

注意：li 最好写在 ul/ol 中，不要单独使用。

## 8. 表格

完整表格由四部分组成：**caption（标题）+ thead（头部）+ tbody（主体）+ tfoot（脚注）**；tr 是行，th/td 是单元格（头部用 th，主体/脚注用 td）。

```html
<table border="1">
    <caption>学生信息</caption>
    <thead>
        <tr>
            <th>姓名</th><th>性别</th><th>年龄</th><th>民族</th><th>政治面貌</th>
        </tr>
    </thead>
    <tbody>
        <tr><td>张三</td><td>男</td><td>18</td><td>汉族</td><td>团员</td></tr>
        <tr><td>李四</td><td>女</td><td>20</td><td>满族</td><td>群众</td></tr>
    </tbody>
    <tfoot>
        <tr><td></td><td></td><td></td><td></td><td>共计：2人</td></tr>
    </tfoot>
</table>
```

**常用属性：**

| 标签 | 属性 |
|---|---|
| table | width、height、border（只控制最外侧边框宽度，内部边框靠 CSS）、cellspacing（单元格间距） |
| thead / tbody / tfoot / tr | height、align（left/center/right）、valign（top/middle/bottom） |
| td / th | width（影响整列）、height（影响整行）、align、valign、**rowspan**（跨行数）、**colspan**（跨列数） |

**跨行跨列**（课程表效果）：

```html
<table border="1">
    <tr>
        <th>课程</th><th>周一</th><th>周二</th><th>周三</th>
    </tr>
    <tr>
        <td rowspan="2">上午</td>
        <td colspan="2">英语</td>
        <td>数学</td>
    </tr>
    <tr>
        <td>语文</td><td>体育</td><td>自习</td>
    </tr>
</table>
```

## 9. 常用标签补充

| 标签 | 语义 | 注意 |
|---|---|---|
| br | 换行 | 不要用 br 增加行间隔，应使用 p 或 CSS margin |
| hr | 分隔 | 想要无语义的水平线应使用 CSS border |
| pre | 按原文显示 | 一般用于在页面中嵌入大段代码 |

## 10. 表单

### 10.1 基本结构

```html
<form action="https://www.baidu.com/s" target="_blank" method="get">
    <input type="text" name="wd">
    <button>去百度搜索</button>
</form>
```

- form：action（提交地址）、target（_self/_blank）、method（get/post）
- input：type（控件类型）、name（提交数据的名字，与后端约定）

### 10.2 常用表单控件

```html
<form action="#" method="post">
    <!-- 文本输入框：name/value(默认值)/maxlength -->
    <p>用户名：<input type="text" name="user" value="默认值" maxlength="10"></p>
    <!-- 密码输入框 -->
    <p>密码：<input type="password" name="pwd" maxlength="16"></p>

    <!-- 单选框：想要单选效果，多个 radio 的 name 必须一致 -->
    <p>性别：
        <input type="radio" name="sex" value="female" id="f"> <label for="f">女</label>
        <input type="radio" name="sex" value="male" checked> 男
    </p>
    <!-- 复选框：name 一致，可多选；checked 默认选中 -->
    <p>爱好：
        <input type="checkbox" name="hobby" value="code"> 写代码
        <input type="checkbox" name="hobby" value="game"> 打游戏
    </p>

    <!-- 隐藏域：用户不可见，提交时携带固定数据 -->
    <input type="hidden" name="tag" value="100">

    <!-- 文本域：rows/cols 控制默认行数列数，不能写 type 属性 -->
    <p>留言：<textarea name="msg" rows="4" cols="30">我是文本域</textarea></p>

    <!-- 下拉框：option 建议写 value（不写则提交 option 中间的文字） -->
    <p>省份：
        <select name="from">
            <option value="黑">黑龙江</option>
            <option value="粤" selected>广东</option>
        </select>
    </p>

    <!-- 按钮：button 的 type 默认是 submit！普通按钮必须写 type="button" -->
    <button type="submit">提交表单</button>
    <button type="reset">重置</button>
    <button type="button">普通按钮</button>
</form>
```

**label 关联控件**（点击文字控件获得焦点）：方式一 `label for="控件id"`；方式二把控件套在 label 里面。

**fieldset + legend 分组**（了解）：

```html
<fieldset>
    <legend>主要信息</legend>
    <label for="zhanghu">账户：</label>
    <input id="zhanghu" type="text" name="account" maxlength="10"><br>
    <label>密码：<input type="password" name="pwd" maxlength="6"></label>
</fieldset>
```

**禁用控件**：input、textarea、button、select、option 均可设置 `disabled`。

## 11. iframe、实体、全局属性、meta

### 11.1 iframe（框架）

在网页中嵌入其他文件（实际应用：嵌入广告；与超链接/表单 target 配合展示不同内容）。属性：name、width、height、frameborder（已废弃，用 CSS border 控制）。

```html
<iframe src="https://www.example.com" width="400" height="300" name="content"></iframe>
```

### 11.2 HTML 实体

符号在 HTML 中有特殊含义（如 `<` 是标签开始），需要用实体表示。实体 = `&` + 名称（或 `&#` + 编号）+ `;`。

| 描述 | 实体名称 | 实体编号 | 描述 | 实体名称 | 实体编号 |
|---|---|---|---|---|---|
| 空格 | &nbsp; | &#160; | 欧元 | &euro; | &#8364; |
| 小于号 | &lt; | &#60; | 版权 | &copy; | &#169; |
| 大于号 | &gt; | &#62; | 注册商标 | &reg; | &#174; |
| 和号 | &amp; | &#38; | 商标 | &trade; | &#8482; |
| 引号 | &quot; | &#34; | 乘号 | &times; | &#215; |
| 元（yen） | &yen; | &#165; | 除号 | &divide; | &#247; |

### 11.3 全局属性（任何标签都能写）

| 属性 | 含义 |
|---|---|
| id | 唯一标识（不能重复），配合 label/CSS/JavaScript |
| class | 类名，配合 CSS 设置样式 |
| style | 直接设置 CSS 样式 |
| dir | 内容方向 ltr / rtl |
| title | 文字提示（超链接和图片用得多） |
| lang | 指定语言 |

### 11.4 meta 元信息

```html
<meta charset="utf-8">                                    <!-- 字符编码 -->
<meta http-equiv="X-UA-Compatible" content="IE=edge">     <!-- IE 兼容（历史遗留） -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">  <!-- 移动端 -->
<meta name="keywords" content="8-12个以英文逗号隔开的词语">   <!-- 网页关键字 -->
<meta name="description" content="80字以内与网站内容相关的描述"> <!-- 网页描述 -->
<meta name="robots" content="index, follow">               <!-- 爬虫：index/noindex/follow/nofollow -->
<meta name="author" content="tony">                        <!-- 作者 -->
<meta name="generator" content="Visual Studio Code">       <!-- 生成工具 -->
<meta name="copyright" content="2023-2027©版权所有">        <!-- 版权 -->
<meta http-equiv="refresh" content="10;url=http://www.baidu.com"> <!-- 10 秒后跳转 -->
```

## 12. 勘误与补充（相对原 PDF）

1. **WHATWF → WHATWG**：原 PDF 组织名拼写错误，全称 Web Hypertext Application Technology Working Group。
2. **webp 兼容性**：原 PDF 称"兼容性不太好"——已过时。2020 年起 Safari 14+ 支持 webp，2026 年所有主流浏览器均支持，是网页图片的优选格式。
3. **a 标签 name 锚点**：原 PDF 教"`<a name="test1">` 设置锚点"——HTML5 中 a 的 name 属性已废弃，统一用**任意标签的 id** 做锚点目标。
4. **table 属性**：border、cellspacing 等属性在 HTML5 中已废弃，边框、间距应通过 CSS 控制（课程后文也承认"靠 CSS 解决"）。
5. **lang 写法**：原 PDF 称"语言-具体种类（zh-Hans）已不推荐"——不准确。zh-Hans/zh-Hant 是合法的 BCP 47 语言标签（语言+文字变体），与 zh-CN（语言+地区）并存，各有用处。
6. **iframe frameborder**：属性已废弃，用 CSS `border: none` 控制。
