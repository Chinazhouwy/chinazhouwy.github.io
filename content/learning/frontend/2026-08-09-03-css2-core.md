# CSS2 核心笔记：选择器、三大特性、盒子模型、浮动与定位

> **来源：** 用户提供的 PDF《CSS2笔记》（42 页，尚硅谷 CSS 入门课程笔记），2026-08-09 整理进 Life OS。
> **整理原则：** 保留课程表格化知识结构，为每节补充可运行示例；对笔误/自相矛盾的表述做了勘误（见文末"勘误与补充"）。

## 0. 这一篇解决什么问题

CSS（Cascading Style Sheets，层叠样式表）给 HTML 结构设置样式，核心思想：**HTML 搭结构，CSS 加样式**，实现结构与样式分离。看完这篇，你能：

1. 三种写样式的方式及优先级，写出规范 CSS
2. 用基本/复合/伪类/伪元素选择器精准选中元素，会算权重
3. 理解盒子模型、margin 塌陷/合并，解决实际布局问题
4. 掌握浮动与四种定位，理解清除浮动的原理

## 1. CSS 基础

### 1.1 三种编写位置

```css
/* 外部样式文件 style.css */
h1 {
    color: red;
    font-size: 40px;
}
```

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>三种样式表</title>
    <!-- 外部样式：写在 head 中，href 引入位置，rel="stylesheet" 说明关系 -->
    <link rel="stylesheet" href="./style.css">
    <!-- 内部样式 -->
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>
<body>
    <!-- 行内样式：写在标签 style 属性中，名:值; 形式 -->
    <h1 style="color:green;font-size:60px;">三种样式同时命中，行内优先</h1>
</body>
</html>
```

| 分类 | 优点 | 缺点 | 作用范围 |
|---|---|---|---|
| 行内样式 | 优先级最高 | 结构与样式未分离、不能复用、代码混乱 | 当前标签 |
| 内部样式 | 样式可复用、结构清晰 | 未彻底分离、不能多页面复用 | 当前页面 |
| 外部样式 | 多页面复用、结构清晰、可触发浏览器缓存 | 需要引入 | 多个页面 |

**优先级**：行内样式 > 内部样式 = 外部样式；同级别中**后面的覆盖前面的**（"后来者居上"）。实际开发几乎都用外部样式。

### 1.2 语法规范与代码风格

```css
/* 选择器：找到要添加样式的元素；声明块：设置具体样式 */
/* 注释写法 */
h1 {
    color: red;       /* 属性名: 属性值; 最后一个分号最好也写 */
    font-size: 40px;
}
```

- 展开风格（开发推荐，便于维护调试）：每行一个声明
- 紧凑风格（上线推荐，减小体积）：`h1{color:red;font-size:40px;}`，上线时用构建工具自动压缩

## 2. CSS 选择器

### 2.1 基本选择器

| 选择器 | 特点 | 用法 |
|---|---|---|
| 通配选择器 | 选中所有元素，一般用于清除样式 | `* {color:red}` |
| 元素选择器 | 选中所有同种标签，不能差异化 | `h1 {color:red}` |
| 类选择器 | 选中特定 class 值的元素（使用频率很高） | `.say {color:red}` |
| ID 选择器 | 选中特定 id 值的唯一元素 | `#earthy {color:red}` |

```css
* { color: gray; }              /* 通配：所有元素 */
h1 { color: orange; }           /* 元素：所有 h1 */
.speak { color: red; }          /* 类：所有 class 为 speak 的元素 */
#earthy { color: red; font-size: 60px; }  /* ID：id 为 earthy 的元素 */
```

```html
<!-- class 属性可以写多个值，用空格隔开；同名的 class 属性写两个是错的 -->
<h1 class="speak big">你好啊</h1>
```

命名规范：class 值不要纯数字、不要中文，多词用 `-` 连接（如 left-menu），见名知意；id 建议字母开头、不含空格、区分大小写；一个元素可同时拥有 id 和 class。

### 2.2 复合选择器

| 选择器 | 作用 | 语法 |
|---|---|---|
| 交集 | 同时满足多个条件 | `p.beauty`（元素+类，用得最多）、`.rich.beauty` |
| 并集 | 多个选择器集体声明（或） | `#peiqi, .rich, .beauty`（一般竖着写） |
| 后代 | 选中祖先中的所有后代（儿子孙子都算） | `ul li`、`.subject li a` |
| 子代 | 只选直接子元素 | `div > a`、`.persons > a` |
| 相邻兄弟 | 紧挨着的下一个兄弟 | `div + p` |
| 通用兄弟 | 后面的所有兄弟 | `div ~ p` |

```css
/* 交集：类名为 beauty 的 p 元素（注意：交集不可能出现两个元素选择器） */
p.beauty { color: blue; }

/* 并集：集体声明，缩小样式表体积 */
#peiqi,
.rich,
.beauty {
    font-size: 40px;
}

/* 后代 vs 子代 */
ul li { color: red; }        /* ul 里所有 li（含孙子） */
ul > li { color: blue; }     /* 只 ul 的直接子 li */

/* 兄弟 */
div + p { color: red; }      /* div 后相邻的兄弟 p */
div ~ p { color: red; }      /* div 后的所有兄弟 p */
```

**属性选择器：**

| 语法 | 含义 |
|---|---|
| `[title]` | 具有某属性的元素 |
| `[title="atguigu"]` | 属性值等于指定值 |
| `[title^="a"]` | 属性值以指定值开头 |
| `[title$="u"]` | 属性值以指定值结尾 |
| `[title*="g"]` | 属性值包含指定值 |

### 2.3 伪类选择器（特殊状态）

**动态伪类**（超链接遵循 LVHA 顺序：link → visited → hover → active）：

```css
a:link    { color: blue; }    /* 未访问 */
a:visited { color: purple; }  /* 已访问 */
a:hover   { color: red; }     /* 悬停 */
a:active  { color: orange; }  /* 按下不松开 */
input:focus { outline: 2px solid blue; }  /* 获得焦点（可聚焦元素均可用，不限表单） */
```

**结构伪类**：

| 伪类 | 含义 |
|---|---|
| :first-child / :last-child | 所有兄弟中的第一个 / 最后一个 |
| :nth-child(n) | 所有兄弟中的第 n 个 |
| :first-of-type / :last-of-type | 同类型兄弟中的第一个 / 最后一个 |
| :nth-of-type(n) | 同类型兄弟中的第 n 个 |

n 的取值：`n` 全选、`2n`/`even` 偶数、`2n+1`/`odd` 奇数、`-n+3` 前 3 个、`0` 或空什么也不选。了解：`:nth-last-child`（倒数）、`:only-child`（独生子女）、`:root`（根元素）、`:empty`（内容为空，空格也算内容）。

```css
/* 斑马纹表格：隔行变色 */
tr:nth-child(even) { background-color: #f5f5f5; }
```

**否定、UI、目标、语言伪类**：`:not(选择器)` 排除满足条件的元素；`:checked` 选中的单选/复选；`:enabled` / `:disabled` 可用/禁用表单；`:target` 锚点指向的元素（了解）；`:lang()` 按语言选择（了解）。

### 2.4 伪元素选择器（特殊位置）

```css
/* ::before / ::after 必须用 content 指定内容 */
.box::before { content: "★ "; color: orange; }
.box::after  { content: " ★"; color: orange; }

p::first-letter { font-size: 32px; }   /* 第一个文字 */
p::first-line   { color: gray; }        /* 第一行 */
p::selection    { background: yellow; } /* 被鼠标选中的内容 */
input::placeholder { color: #999; }     /* 输入框提示文字 */
```

### 2.5 选择器权重（优先级）

样式冲突时按权重决定，格式 **(a, b, c)**：

- a：ID 选择器个数
- b：类、伪类、属性选择器个数
- c：元素、伪元素选择器个数

| 选择器 | 权重 |
|---|---|
| `ul > li` | (0,0,2) |
| `div ul > li p a span` | (0,0,6) |
| `#atguigu .slogan` | (1,1,0) |
| `#atguigu .slogan a:hover` | (1,2,1) |

比较规则：从左到右依次比较，当前位胜出后面不再比，如 (1,0,0) > (0,2,2)。
特殊规则：行内样式 > 一切选择器；`!important` > 行内样式 > 一切选择器（权重最高，慎用）。

## 3. CSS 三大特性

1. **层叠性**：同一个样式名被设置不同值即冲突，按选择器优先级层叠（覆盖）
2. **继承性**：元素自动拥有祖先设置的某些样式，优先继承离得近的。可继承：text-*、font-*、line-*、color 等；不可继承：边框、背景、padding、margin、宽高、overflow（规律：影响布局的都不继承）
3. **优先级**：`!important` > 行内样式 > ID 选择器 > 类选择器 > 元素选择器 > `*` > 继承的样式

注意：并集选择器的每一部分分开计算权重（`:not()` 内部的选择器参与计算，`:not()` 本身不参与）。

## 4. CSS 常用属性

### 4.1 像素与颜色

- 屏幕由一个个小点组成，每个点就是一个像素（px）；像素点越小越清晰细腻
- 颜色四种写法（开发常用 rgb/rgba 和 HEX/HEXA）：

```css
color: red;                       /* ① 颜色名 */
color: rgb(255, 0, 0);            /* ② rgb：0~255 或百分比 */
color: rgba(255, 0, 0, 0.5);      /*    a=透明度，0~1 */
color: #ff0000;                   /* ③ HEX：#rrggbb，每位 0~f；#ff9988 可简写 #f98 */
color: #ff998866;                 /*    HEXA：#rrggbbaa，可简写 #f986 */
color: hsl(0, 100%, 50%);         /* ④ HSL：色相 0~360°、饱和度 0~100%、亮度 0~100% */
color: hsla(0, 100%, 50%, 0.5);   /*    HSLA 加透明度 */
```

小规律：rgb 三值相同为灰色，值越大灰越浅；rgb(0,0,0) 黑，rgb(255,255,255) 白。注意：IE 不支持 HEXA 但支持 HEX（2026 年已无关紧要）。

### 4.2 字体属性

| 属性 | 作用 | 常用值 |
|---|---|---|
| font-size | 字体大小 | 像素值；Chrome 默认 16px，有最小字号限制（约 12px，与浏览器设置相关） |
| font-family | 字体类型 | 多个字体从前往后找，找不到用后面的，最后写 serif/sans-serif 兜底；含空格的字体名用引号 |
| font-style | 斜体 | normal / italic（推荐）/ oblique |
| font-weight | 粗细 | lighter / normal / bold / bolder；数值 100~1000（400≈normal，600+≈bold） |
| font | 复合属性 | `font: italic bold 40px "Microsoft YaHei", sans-serif;` 大小和字体族必写，且大小倒数第二位、字体族最后一位 |

```css
body {
    font-size: 16px;              /* 给 body 设置，其他元素可继承 */
}
div {
    font: italic 600 20px "STCaiyun", "Microsoft YaHei", sans-serif;
}
```

### 4.3 文本属性

| 属性 | 作用 | 常用值 |
|---|---|---|
| color | 文字颜色 | 颜色名 / rgb / HEX / HSL |
| letter-spacing | 字母间距 | px，负值缩小 |
| word-spacing | 单词间距 | px（按空格识别词） |
| text-decoration | 装饰线 | none（去下划线，常用）/ underline / overline / line-through；可配 dotted/wavy/颜色 |
| text-indent | 首行缩进 | px，如 2em 缩进两字符 |
| text-align | 水平对齐 | left（默认）/ right / center |
| line-height | 行高 | normal / px / 数字（自身 font-size 的倍数，最常用）/ 百分比 |
| vertical-align | 行内垂直对齐 | baseline（默认）/ top / middle / bottom；**不能控制块元素** |

```css
a { text-decoration: none; }          /* 去掉超链接下划线 */
p { text-indent: 2em; }               /* 首行缩进两字符 */
.title { text-align: center; }        /* 水平居中 */
.btn {
    height: 40px;
    line-height: 40px;                /* 单行文字垂直居中：height = line-height */
}
img { vertical-align: middle; }       /* 图片与文字垂直居中对齐 */
```

行高注意：过小文字重叠（最小 0，不能为负）；设置 height 后高度即 height 的值，不设 height 时按 line-height 计算。

### 4.4 列表 / 表格 / 背景 / 鼠标

| 属性 | 作用 | 常用值 |
|---|---|---|
| list-style-type | 列表符号 | none（最常用）/ square / disc / decimal / lower-roman / upper-alpha |
| list-style-position | 符号位置 | inside / outside |
| list-style-image | 自定义符号 | url(图片地址) |
| list-style | 复合属性 | 无顺序数量要求 |

表格独有属性：table-layout（auto 默认 / fixed 固定列宽）、border-spacing（单元格间距）、border-collapse（collapse 合并 / separate 不合并）、empty-cells（show / hide，前提是不合并边框）、caption-side（top / bottom）。

```css
ul { list-style: none; }        /* 去掉列表符号 */
table { border-collapse: collapse; }  /* 合并单元格边框，最常见的表格样式 */
```

| 属性 | 作用 | 常用值 |
|---|---|---|
| background-color | 背景颜色 | 颜色值，默认 transparent |
| background-image | 背景图片 | url(地址) |
| background-repeat | 重复方式 | repeat（默认）/ repeat-x / repeat-y / no-repeat |
| background-position | 位置 | 关键字（left/center/right + top/center/bottom，只写一个另一个取 center）；或 x y 长度坐标 |
| background | 复合属性 | 无顺序数量要求 |
| cursor | 鼠标样式 | pointer / move / text / crosshair / wait / help；自定义 `cursor: url(./arrow.png), pointer;` |

## 5. 盒子模型

### 5.1 长度单位

px（像素）、em（相对自身 font-size 的倍数）、rem（相对根 html 的 font-size）、%（相对父元素）。**CSS 中设置长度必须加单位，否则样式无效。**

### 5.2 显示模式

| | 块元素 block | 行内元素 inline | 行内块 inline-block |
|---|---|---|---|
| 排列 | 独占一行 | 不独占一行 | 不独占一行 |
| 默认宽度 | 撑满父元素 | 内容撑开 | 内容撑开 |
| 默认高度 | 内容撑开 | 内容撑开 | 内容撑开 |
| 设置宽高 | 可以 | **不可以** | 可以 |

- 块元素：h1~h6、hr、p、pre、div、ul/ol/li、dl/dt/dd、表格相关、form、option
- 行内元素：br、em、strong、sup、sub、del、ins、a、label
- 行内块：img、td/th、input、textarea、select、button、iframe
- 用 `display` 修改：`none`（隐藏，不占位）/ `block` / `inline` / `inline-block`

### 5.3 盒子组成

```
┌──────────────────────────── margin 外边距（不影响盒子大小，影响位置）───┐
│  ┌──────────────────────── border 边框 ────────────────────────┐  │
│  │  ┌────────────────────── padding 内边距 ──────────────────┐  │  │
│  │  │  ┌────────────────── content 内容 ──────────────────┐  │  │  │
│  │  │  │                                                  │  │  │  │
```

**盒子大小 = content + 左右 padding + 左右 border**（margin 不影响大小，只影响位置）。

### 5.4 content / padding / border / margin

```css
.box {
    /* content */
    width: 200px;
    height: 100px;
    min-width: 100px;   /* max/min 一般不与 width 一起用 */

    /* padding：1~4 个值，顺时针（上 右 下 左）；不能为负 */
    padding: 10px;              /* 四边 10px */
    padding: 10px 20px;         /* 上下 10px，左右 20px */
    padding: 10px 20px 30px;    /* 上 10px，左右 20px，下 30px */
    padding: 10px 20px 30px 40px;

    /* border：共 20 个属性（style/width/color × 四方向 + 复合） */
    border: 2px solid red;              /* 复合：宽度 风格 颜色 */
    border-bottom: 1px dashed #ccc;     /* 只画下边框 */

    /* margin：1~4 个值，规律同 padding；可以是负值 */
    margin: 0 auto;                     /* 块级元素水平居中（左右 auto） */
}
```

**默认宽度**：不设置 width 时，总宽度 = 父 content − 自身左右 margin；内容区宽度 = 总宽度 − 左右 border − 左右 padding。

**margin 注意事项**：
1. 子元素 margin 参考父元素 content 计算
2. 上/左 margin 影响自己位置；下/右 margin 影响后面兄弟元素位置
3. 行内元素只能完美设置左右 margin，上下无效（padding 同理）
4. 负值可用（如 `margin-top: -20px` 上移元素）

**margin 塌陷**（经典面试题）：第一个子元素的上 margin 会作用到父元素上（最后一个子元素的下 margin 同理）。
解决：①父元素设置不为 0 的 padding；②父元素设置不为 0 的 border；③父元素 `overflow: hidden`（或开启 BFC，见 CSS3 笔记）。

**margin 合并**：上下兄弟元素的外边距会合并取**最大值**（不是相加）。无需解决，布局时只给一个元素设置即可。

```css
/* 塌陷演示与修复 */
.parent { background: #eee; overflow: hidden; }  /* 修复：开启 BFC */
.child { margin-top: 30px; }
```

### 5.5 溢出、隐藏、继承、默认样式

| 属性 | 作用 | 常用值 |
|---|---|---|
| overflow | 溢出内容处理 | visible（默认）/ hidden / scroll / auto（最常用 hidden 和 auto） |
| overflow-x / overflow-y | 单方向 | 同 overflow（两者不能一个 hidden 一个 visible，实验属性不建议用） |

隐藏元素两种方式对比：

| 方式 | 效果 |
|---|---|
| `visibility: hidden` | 看不见但**占位**（默认值是 visible，原 PDF 误写 show） |
| `display: none` | 彻底隐藏，**不占位** |

**默认样式**：a（下划线+颜色+小手）、h1~h6（加粗+上下 margin）、p（上下 margin）、ul/ol（左 padding）、body（8px 外边距）。默认样式优先级 > 继承样式，重置需直接选中元素。

**布局小技巧**：
- 行内/行内块元素可被父元素当文本处理（text-align、line-height、text-indent 对齐）
- 块级子元素水平居中：子元素自身 `margin: 0 auto`（原 PDF 误写"给父元素加"，见勘误）
- 行内/行内块子元素水平居中：父元素 `text-align: center`
- 单行文字垂直居中：`height = line-height`

**空白问题**：行内/行内块元素之间的换行会被解析成一个空白字符。解决：①去掉换行（不推荐）；②父元素 `font-size: 0`，需要文字的元素单独设置字号（推荐）。

**幽灵空白问题**：行内块元素与文本基线对齐产生底部空隙。解决：①vertical-align 设为 middle/bottom/top；②父元素只有一张图片时给图片 `display: block`；③父元素 font-size: 0。

## 6. 浮动

浮动最初用于文字环绕图片，现在作为主流布局方式之一（flex 出现前）。

**浮动后的特点**：脱离文档流；宽高被内容撑开且可设置宽高；不独占一行；不会 margin 塌陷/合并；没有行内块空白问题。

**浮动的影响**：后面的兄弟元素会占据浮动元素之前的位置（前面的兄弟无影响）；不能撑起父元素高度（父元素高度塌陷），但父元素宽度依然束缚浮动元素。

**清除浮动（5 种方案）**：①父元素指定高度；②父元素也浮动（带来其他影响）；③父元素 `overflow: hidden`；④浮动元素最后加一个块级元素 `clear: both`；⑤**伪元素方案（推荐）**：

```css
/* clearfix：推荐方案，原理同方案四 */
.parent::after {
    content: "";
    display: block;
    clear: both;
}
```

```html
<!-- 布局原则：兄弟元素要么全都浮动，要么全都不浮动 -->
<div class="parent">
    <div class="left" style="float:left;">左栏</div>
    <div class="right" style="float:right;">右栏</div>
</div>
```

**浮动属性**：`float: left / right / none`；`clear: left / right / both`（清除前面兄弟浮动元素的影响）。

## 7. 定位

| | 相对定位 relative | 绝对定位 absolute | 固定定位 fixed | 粘性定位 sticky |
|---|---|---|---|---|
| 参考点 | 自己原来的位置 | 包含块（最近的定位祖先，都没有则整个页面） | 视口（浏览器窗口） | 最近的滚动祖先 |
| 脱离文档流 | 否 | 是 | 是 | 否 |
| 特点 | 视觉移动，不影响其他元素 | 元素变为定位元素（宽高内容撑开、可设宽高） | 同绝对定位 | 到达某位置时固定（最常用 top 值） |

```css
/* 经典：子绝父相 —— 父元素相对定位做参考，子元素绝对定位 */
.parent { position: relative; }
.child {
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);   /* 位移自身一半，实现精确居中 */
}
/* 拉伸定位：同时设置 left:0 right:0 让宽度充满包含块（top/bottom 同理） */
.stretch {
    position: absolute;
    left: 0;
    right: 0;
    top: 0;
    bottom: 0;
    margin: auto;   /* 四边为 0 + margin auto = 水平垂直居中（需设置宽高） */
}
/* 固定导航条 */
.nav {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
}
```

**层级**：定位元素显示层级高于普通元素；都定位时后写的盖在先写的之上；`z-index`（数字无单位，越大越高）只对定位元素有效；z-index 大仍盖不住时检查包含块的层级。

注意（原 PDF 前后矛盾处，见勘误）：relative 同时设置 left 和 right 时只有一个生效（另一个被忽略）；**absolute/fixed 同时设置 left:0 和 right:0 是合法的拉伸定位**，不是"不能一起设置"。

- **版心**：PC 端网页中固定宽度且水平居中的盒子，一般 960~1200px，可以一个或多个

## 9. 勘误与补充（相对原 PDF）

1. **visibility 默认值**：原 PDF 写"默认值是 show"——错误，CSS 中 visibility 的取值是 `visible` / `hidden` / `collapse`，默认值是 **visible**。
2. **水平居中写法**：原 PDF 布局技巧写"若子元素为块元素，给父元素加上 margin: 0 auto"——错误。`margin: 0 auto` 要写在**块级子元素自己**身上（父元素加的是 text-align: center，仅对行内/行内块有效）。
3. **left/right 能否同时设置**：原 PDF 先说"left 不能和 right 一起设置"，后面又说"同时设置 left/right 为 0 让宽度充满包含块"——自相矛盾。准确规则：**relative 同时设置 left/right 只有一个生效**；**absolute/fixed 同时设置 left:0; right:0 是合法的拉伸定位**，也是常用技巧。
4. **:focus 的适用范围**：原 PDF 称"表单类元素才能使用"——不准确。所有可聚焦元素（含设置了 tabindex 的任意元素）都能用 :focus。
5. **Chrome 最小字号**：原 PDF 称"Chrome 支持的最小文字为 12px"——与浏览器设置相关（设置→外观→自定义字体中的最小字号，默认约 12px）。需要更小字号时常用 `transform: scale()` 实现。
6. **:not() 权重**：原 PDF 未提——:not() 本身不参与权重计算，但括号内选择器参与。
7. **幽灵空白**：原 PDF 的方案一漏了"vertical-align 设为 middle/bottom/top"的写法，已补全。
