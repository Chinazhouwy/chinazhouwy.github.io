# 单位圆视角下的三角函数公式

> 原文标题：一堆三角函数公式，其实只是一个点在单位圆上不停地滚来滚去
>
> 来源：微信公众号「曹古拉斯大魔王」

> 发布时间：2026-09-01 18:51（北京时间）

## 一、核心观点

三角函数公式看起来很多，但它们并不是几十条互不相关的规则。把问题放回单位圆后，大部分公式都可以还原为同一个几何动作：

- 一个点在单位圆上转动；
- 横坐标和纵坐标互相转换；
- 点关于坐标轴或原点对称；
- 图形连续旋转；
- 对旋转关系进行重复或反向推导。

因此，学习重点不应只是背口诀，而是建立“**一个点、一个圆、两个坐标**”的统一模型。

## 二、正弦和余弦就是同一个点的两个坐标

设单位圆上的点为 `P(θ)`，其坐标是：

```text
P(θ) = (cos θ, sin θ)
```

于是：

- `cos θ` 是点的横坐标；
- `sin θ` 是点的纵坐标。

因为点始终位于单位圆上，所以满足：

```text
cos²θ + sin²θ = 1
```

这条关系并不是凭空规定的三角函数技巧，而是单位圆方程：

```text
x² + y² = 1
```

它的底层就是勾股定理。

## 三、诱导公式来自对称

诱导公式本质上是在问：角度变化后，单位圆上的点移动到了哪里，横坐标和纵坐标分别有没有变号。

### 1. 关于纵轴对称

`θ` 与 `π - θ` 对应的点关于纵轴对称：

```text
P(θ)       = ( cos θ, sin θ)
P(π - θ)   = (-cos θ, sin θ)
```

所以：

```text
sin(π - θ) =  sin θ
cos(π - θ) = -cos θ
```

### 2. 关于原点对称

`θ` 与 `π + θ` 对应的点互为相反点，横纵坐标都变号：

```text
sin(π + θ) = -sin θ
cos(π + θ) = -cos θ
```

常见口诀“奇变偶不变，符号看象限”，只是把这些对称关系压缩成了记忆形式。理解坐标如何变化，比单独背口诀更稳。

## 四、正弦和余弦互换来自旋转 90 度

角度满足：

```text
π/2 - θ
```

可以理解为把原来的方向旋转 90 度后，再取余下的角度。旋转 90 度会交换横、纵方向，因此：

```text
sin(π/2 - θ) = cos θ
cos(π/2 - θ) = sin θ
```

正弦和余弦不是两套完全独立的系统，而是同一个点在两个互相垂直方向上的投影。

## 五、和角公式来自连续旋转

设单位圆上的点先旋转 `α`，再旋转 `β`。两次旋转合起来，等价于旋转 `α + β`。

用二维旋转矩阵表示：

```text
R(θ) =
[ cos θ  -sin θ ]
[ sin θ   cos θ ]
```

旋转的复合满足：

```text
R(α)R(β) = R(α + β)
```

比较矩阵中的元素，就得到和角公式：

```text
cos(α + β) = cos α cos β - sin α sin β
sin(α + β) = sin α cos β + cos α sin β
```

所以和角公式不是凭空出现的记忆负担，而是在描述“一个点连续旋转两次之后的新坐标”。这也说明中学三角函数已经和线性代数中的坐标变换、旋转矩阵连接起来了。

## 六、倍角和半角公式是和角公式的变形

### 1. 倍角公式

令 `α = β = θ`：

```text
sin(2θ) = 2sin θ cos θ
cos(2θ) = cos²θ - sin²θ
```

倍角公式只是“同一个角连续旋转两次”。不必把它当成一套新的、独立的公式。

### 2. 半角公式

把倍角公式反过来整理，可以得到：

```text
cos²(θ/2) = (1 + cos θ) / 2
sin²(θ/2) = (1 - cos θ) / 2
```

半角公式是对倍角关系的逆向推导，使用开平方时还要结合角度范围判断正负号。

## 七、不同数学语言是在描述同一个动作

同一个结构可以用不同语言表达：

| 观察角度 | 三角函数对应的含义 |
|---|---|
| 几何 | 单位圆上的点和旋转 |
| 坐标 | 点的横坐标与纵坐标 |
| 三角形 | 边长之比 |
| 函数 | 周期性变化 |
| 物理 | 波动和振动 |
| 线性代数 | 旋转矩阵和坐标变换 |
| 复数 | 复平面上的旋转 |

在复数中，欧拉公式把旋转写得非常紧凑：

```text
e^(iθ) = cos θ + i sin θ
```

于是：

```text
e^(iα)e^(iβ) = e^(i(α + β))
```

展开左边后，就会重新得到和角公式。看似不同的公式，实际上是同一个旋转结构在不同数学语言中的表达。

## 八、复习方法

遇到三角函数变形时，可以按以下顺序检查：

1. **先画单位圆**，确认角度对应的点和象限；
2. **判断是对称还是旋转**；
3. **看横坐标、纵坐标是否交换或变号**；
4. **和角问题使用旋转复合**；
5. **倍角、半角优先从和角公式推导**；
6. **最后再用口诀做快速检查**。

## 九、边界与易错点

- 单位圆视角能解释公式来源，但不能替代定义域、象限和符号判断；
- `tan θ = sin θ / cos θ` 的前提是 `cos θ ≠ 0`；
- 使用半角公式开平方时，正负号必须由角度范围决定；
- 图形直觉适合建立结构，具体计算仍要结合代数变形；
