# 拉普拉斯算子

拉普拉斯算子
在亥姆霍兹方程 (Helmholtz Equation) 和波动方程中，都涉及到一个算子，即拉普拉斯算子 。 那么就看看什么是拉普拉斯算子，以及拉普拉斯算子又代表了什么？
是拉普拉斯算子（Laplacian），在三维直角坐标系中是 。
一句话概括：拉普拉斯算子衡量的是某一点的函数值，与其周围微小区域内平均值的差异。
梯度的散度
拉普拉斯分解开来就是其实就是梯度的散度，至于梯度和散度的定义，以后再说，简单来说，梯度代表“坡度”的方向，散度代表“通量”的源汇。
物理直觉
想象一个函数 代表地形的高度。
1. 梯度 ()：箭头的指向
梯度的定义是指向函数增加最快的方向。
如果你在一个山峰上：不管往哪个方向走都是下坡，所以四周的梯度箭头都指向你（指向高处）。
如果你在一个坑底里：不管往哪个方向走都是上坡，所以四周的梯度箭头都背离你（指向四周的高处）。
2. 散度 ()：箭头的汇聚与发散
散度的定义是衡量矢量场是“发散出去”还是“汇聚进来”。
发散（散度 > 0） ：箭头像爆炸一样向四周散开。
汇聚（散度 拉普拉斯值为负');

例子 2：边缘检测（图像处理中的突变）
拉普拉斯算子对变化剧烈的地方非常敏感。
在平坦区域（颜色一样），。
在边缘（颜色突然变化）， 会出现剧烈的正负波动。
```
% === 2. 图像边缘检测 ===
clear; clc;
% 创建一个简单的图像：中间有一个方块，背景是黑的
Img = zeros(100, 100);
Img(30:70, 30:70) = 1; % 白色方块
% 定义拉普拉斯卷积核 (3x3 离散算子)
% 核心逻辑：中心点 * 4 - 上下左右四个点的和 (或者反过来)
kernel = [0 1 0;
1 -4 1;
0 1 0];
% 进行卷积运算 (应用拉普拉斯算子)
LapImg = conv2(Img, kernel, 'same');
% 绘图
figure('Name', '边缘检测', 'Color', 'w');
subplot(1, 2, 1);
imagesc(Img); colormap gray; axis square; title('原始图像');
subplot(1, 2, 2);
imagesc(LapImg); axis square; title('拉普拉斯运算结果');
colorbar;
disp('观察右图：');
disp('1. 黑色背景和白色内部（平坦区域），值为 0（灰色）。');
disp('2. 在边界处，你可以看到明显的亮线和暗线。');
disp('这说明拉普拉斯算子提取出了“发生变化”的轮廓。');
```
