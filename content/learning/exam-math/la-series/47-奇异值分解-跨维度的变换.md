# 奇异值分解，跨维度的变换

在奇异值的文章中，其实已经把奇异值分解的整体思路以及意义描述的差不多了，本文再详细的描述一边，从分解的角度。
关于旋转 — 拉伸 — 旋转
矩阵是什么？ 一行行数字摆在那。但数字不是矩阵的本体——矩阵只是变换在特定坐标系下投下的影子。
真正的本体是「变换」：把一个空间拉过来、揉一把，将向量拧到另一个方向去的那个物理动作。这个动作没有坐标。
给它套上一组坐标轴，它就显形成矩阵 。换一组轴，同一个变换就会显形成另一个面目全非的矩阵 。矩阵长什么样，完全取决于观察者从哪个角度看。
普通的矩阵乘法 会把空间搞得极其扭曲、面目全非——向量既在旋转，又在拉伸，甚至可能从 3 维直接塌陷到 2 维。
SVD 说的是总能找到两组绝配的基——输入空间一组（），输出空间一组（） 。在这两组轴底下，这个复杂的变换看起来就会变成最纯粹、最简单的对角拉伸。
```
(V^T) (Σ) (U)
输入向量 --------> 旋转 --------> 沿轴拉伸 --------> 旋转 --------> 输出
```
任意一个杂乱无章的矩阵，在变换的层面上都是同一回事：旋转拉伸旋转。再复杂的物理暴力，也一定能被拆解成三步最清爽的优雅动作：
1. （第一步：纯旋转） ：它不改变任何向量的长度。它的唯一任务，是把输入空间旋转到一个天造地设的完美角度。
2. （第二步：只在主轴上拉伸） ：在这个完美角度下，空间完全没有旋转，只剩下纯粹的、沿着几条相互垂直的坐标轴方向的拉伸或压缩。拉伸的倍数就是奇异值。
3. （第三步：纯旋转） ：最后，把拉伸好的成果，在输出空间里再次进行一次纯粹的旋转，落到最终的坐标系里。
这就是矩阵的几何骨架：不管数据看起来多乱，它本质上都只是把空间转到一个舒服的角度，扯一扯，再转到最终的位置。
这里可以思考一下，与特征分解有什么不同，特征值也是体现了拉伸的效果。
吉尔伯特·斯特朗（Gilbert Strang）讲述了矩阵的四个基本子空间（The Four Fundamental Subspaces）：
行空间（Row Space） ：矩阵行向量能撑起的所有可能空间（输入的有效空间）。
零空间（Null Space） ：所有被矩阵无情抹杀、揉成零向量的那些向量的居所。
列空间（Column Space） ：矩阵列向量能撑起的所有可能空间（输出的有效空间）。
左零空间（Left Null Space） ：映射过去后，输出空间里那些矩阵根本到达不了的死角。
在没有 SVD 之前，这四片空间虽然客观存在，但它们的基向量往往是歪歪扭扭的，彼此之间关系混乱。而 SVD 一亮剑，奇迹发生了：它极为大度、极其精准地为这四片复杂的空间，各自裁剪出了一套完美契合的标准正交基！

SVD是关于最优的陈述
在实际工程和高维数据处理中（比如面对几千维的图像、或者毫米波设备海量的多通道原始采样），永远在和算力、内存、带宽做斗争。保留完整的矩阵 成本太高了，必须降维——寻找一个更简单的、秩不超过 的矩阵 来代替它。
SVD 给出答案：不需要做任何漫无目的的搜索，只需要把 SVD 拆出来的奇异值矩阵 拿过来，保留前个最大的奇异值，把剩下的全部无情抹杀成 0（截断为） ，再乘回 和 。
这个 就是全宇宙最完美的逼近。在代价有限（Rank）的约束下，人类能从矩阵中榨取出的最大有效信息是多少。
在实际的压缩、降噪、特征提取中，只需要画出奇异值能量累计图，找到那个能量增长开始躺平的拐点（Elbow Point）：
1. 信号/图像压缩：把一个大矩阵砍掉 90% 的冗余维度，只留下能撑起 能量的前 个奇异值。这就把一张几兆的图压成了几KB，但肉眼看过去，画面依然清晰，因为最能干的那几件事被完美保留了。
2. 信号去噪：噪声的特点是能量低、方向杂，它们通常均匀地散落在那些极小的小奇异值里。当一刀切下去，抹杀掉尾部奇异值的同时，本质上是在物理上对信号进行了一次最高级的真空去噪。

从几何上看，这个变换会将二维实数平面上的每一个非零向量都转动一个角度。
1. 实数域的失效：既然每一个向量的方向都发生了偏转，那么在实数空间 中，就绝对不存在任何一个向量，能够满足变换后依然与原方向共线的条件。
2. 复数域的引入：为了让代数方程 依然有解（满足代数基本定理），我们必须将坐标系从实数空间扩展到复数空间 。
3. 虚部的几何含义：此时解出的特征值 必然带有虚部（表现为共轭复数 ）。在数学上，复数特征值的模长代表了变换的拉伸比例，而它的辐角（Phase Angle）则极其精准地记录了空间旋转的角度。
它强制矩阵必须在自身相同的输入与输出空间里寻找完全不发生旋转的方向。如果矩阵的物理本质包含旋转（如复阻抗分析、交流电电路分析、或者是电磁波的圆极化），它无法在实数坐标系里妥协，就必须借由复数（虚部）来打数学补丁，以此来同时表达拉伸与旋转这两个复合动作。

2. 矩阵变换（旋转） ：矩阵 对这组基进行整体旋转。
3. 寻找输出基：由于正交变换（纯旋转）不改变向量的长度和夹角，这组基被旋转后，在输出空间中依然保持严格的标准正交。我们直接将这组旋转后的新基指定为输出空间的坐标系 。

特征分解与奇异值分解的关系
从范围和数值上看，奇异值分解（SVD）确实显得比特征分解大包大揽：任何矩阵都有奇异值，而特征分解只能处理方阵。
如果从严谨的数学定义和集合论的视角，奇异值分解，特征分解更像是两个独立发展、但在特定区域产生重合（相交）的工具体系。
特征值可以是复数：当一个方阵包含旋转动作时，它的特征值一定是复数（比如 ）。
奇异值必须是纯实数，且全为非负数：因为奇异值量度的是超椭球体各根轴的绝对长度，长度不可能是虚数，也不可能是负数（）。
而且奇异值，是无法反推出它的特征值的。
特征分解保留了方向和相位， 特征分解强迫输入输出共用一套坐标系（）。它的特征值和特征向量是死死绑定在一起的。复数特征值里的虚部，极为敏感地记录了空间旋转了多少度（相位信息） 。
SVD 过滤了旋转， SVD 为了让中间的奇异值变得干净、可信，允许输入 和输出 使用不同的坐标系。它把所有的空间旋转、角度全部倾倒给了两边的正交矩阵 和 。中间的奇异值只孤零零地记录了纯粹的拉伸力度。
因为 SVD 把旋转信息全部剥离并扔到了外面的 和 里，导致孤立的奇异值谱丢失了方阵的固有旋转方向。
