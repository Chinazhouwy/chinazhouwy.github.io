# 数学：从公式堆到问题地图

> 【卡片封面】数学不是把公式背得越多越好，而是看到题目后，能判断它正在考哪条关系。

## 01｜先画三条主线

| 主线 | 研究对象 | 看到题目先问什么 |
|---|---|---|
| 高等数学 | 变化、累积、逼近 | 这是局部变化，还是整体累积？ |
| 线性代数 | 向量、空间、变换 | 这是方程组的解，还是线性变换的结构？ |
| 概率论 | 随机性、分布、平均 | 这是事件关系，还是随机变量的数字特征？ |

高数解决“函数如何变化”，线代解决“空间如何被变换”，概率解决“随机结果如何被描述”。三门课的公式看起来不同，但解题动作都可以归纳成三步：

1. 把题目翻译成对象和条件。
2. 找到条件之间不变量或可转换的关系。
3. 用最短的计算验证结论。

## 02｜高数地图：先抓连接处

```text
极限 / 连续
    ↓
导数 / 微分 / 中值定理
    ↓
积分 / 级数 / 微分方程
    ↓
多元函数 / 重积分 / 曲线曲面积分
```

高数最容易丢分的地方不是单个公式，而是“连接处”：

- 极限告诉你能不能逼近，连续告诉你能不能无断点地接上。
- 导数描述局部变化，中值定理把局部变化连接到区间整体。
- 定积分描述累积，微积分基本定理把累积和变化连接起来。
- 泰勒公式把函数在一个点附近的行为，替换成多项式的可计算行为。

## 03｜线代地图：方程组只是入口

```text
线性方程组 Ax = b
       ↓
矩阵的秩 / 线性相关性
       ↓
特征值与特征向量
       ↓
二次型与正交变换
```

不要只把秩当成“消元后非零行的数量”。它同时回答：

- 列向量张成了多大的空间？
- 方程组的约束有多少条真正独立？
- 齐次方程组有没有非零解？
- 一个线性变换有没有丢失维度？

## 04｜概率地图：分布是主语，数字特征是压缩

```text
事件关系 → 随机变量 → 分布函数 / 密度
                         ↓
                期望 / 方差 / 协方差
                         ↓
                  大数定律 / 极限定理
```

概率题不要上来就套密度积分。先确认：随机变量是什么，取值范围是什么，题目给的是分布函数、密度还是联合分布。不同课程的覆盖范围并不完全相同，学习时先确认当前目标，再选择对应的内容深度。

## 05｜每张卡片的固定背面

每学完一个主题，留下五行复盘：

```text
它解决什么问题：
题目出现什么信号：
核心关系是什么：
最容易误用的条件：
我能否不用看答案讲清楚：
```

## 一句话结论

数学的主线不是“公式 → 题目”，而是“问题结构 → 工具选择 → 条件验证 → 结果解释”。后续每张卡只讲一个问题，避免把整章再次压成一张目录。
