## 一、为什么值得收藏

这套内容不是把公式堆在一起，而是试图用“空间—变换—不变量”的主线理解线性代数：

- 从向量、线性组合、张成空间和基，建立“空间”的语言
- 通过矩阵描述线性方程组与线性变换
- 用行列式、秩、特征值和特征向量寻找变换的不变量
- 进一步进入二次型、正定矩阵、协方差、投影、特征分解和奇异值分解
- 再把这些概念连接到微积分、傅里叶分析、概率和最小二乘等应用

适合把它当作一张**概念地图和查阅目录**，再按自己的基础选择文章精读；不要把 60 篇当成必须一次读完的线性任务。

## 二、原合集页面的六部分结构

合集目录页按以下六部分组织：

### 1. 向量空间及其性质

什么是向量、线性组合与向量空间、张成空间与基、向量内积，以及向量空间与内积的回顾延伸。

### 2. 矩阵

矩阵与线性方程组、矩阵加法和乘法、特殊矩阵、幂运算与转置、矩阵乘法的意义、线性变换矩阵、矩阵的秩与秩零定理。

### 3. 行列式

行列式定义、几何意义、相关概念与基本性质。

### 4. 相似矩阵

坐标变换、过渡矩阵与相似矩阵。

### 5. 特征向量与对角化

特征值与特征向量、矩阵对角化、正交矩阵、相似矩阵中的不变量。

### 6. 回顾延伸与拓展

二次型、正定矩阵、协方差矩阵、内积与投影、特征分解、奇异值与奇异值分解。

## 三、建议学习路线

### 路线 A：先建立线性代数主干

```
向量
  → 线性组合与向量空间
  → 张成空间与基
  → 内积与投影
  → 矩阵与线性方程组
  → 秩与行列式
  → 线性变换
  → 特征值/特征向量
  → 对角化与正交矩阵
  → 二次型/正定矩阵
  → 特征分解与奇异值分解
```

### 路线 B：按问题类型学习

| 想解决的问题 | 优先阅读主题 |
|---|---|
| 如何表达一个空间和空间中的方向？ | 向量、线性组合、张成空间、基、内积 |
| 如何表示和求解线性关系？ | 矩阵、线性方程组、秩、行列式 |
| 一个变换在换坐标后是否还是同一个变换？ | 坐标变换、过渡矩阵、相似矩阵 |
| 如何找出变换中不会改变的方向？ | 特征值、特征向量、对角化 |
| 如何度量空间中的长度、角度和能量？ | 内积、正交矩阵、正定矩阵、二次型 |
| 如何处理非方阵或降维问题？ | 最小二乘、特征分解、奇异值、SVD |
| 这些概念如何进入信号、统计和概率？ | 卷积、傅里叶、拉普拉斯、协方差、中心极限定理 |

### 路线 C：面向计算机和数据方向的重点

1. 向量空间、基、内积与投影：理解特征表示和相似度
2. 矩阵乘法与线性变换：理解数据在不同空间之间的映射
3. 秩、线性方程组和最小二乘：理解可解性与拟合
4. 特征值、特征向量和对角化：理解稳定方向与谱方法
5. 协方差矩阵和正定矩阵：理解相关性、能量与优化
6. SVD：理解降维、低秩近似和非方阵分解
