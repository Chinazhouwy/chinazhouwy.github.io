# 一张单位圆，推完最常用的40个三角函数公式

> 来源：微信公众号「起什么好3211」· 开学数学速查 · 单位圆公式树
>
> 原文链接：<https://mp.weixin.qq.com/s/h942K0gdwOtlg_st5lyw-g>
>
> 关联笔记：[单位圆视角下的三角函数公式](./2026-09-01-unit-circle-trigonometric-formulas.md)（同一视角的概念篇，本文是公式全集篇）

## 核心观点：40条公式只有三条树根

三角函数的诱导、和差角、倍角、半角、积化和差、和差化积不是40个互不相关的知识点，它们更像同一棵树上长出的叶子。**树根只有三条**：

1. 单位圆上的点，坐标是 `(cosθ, sinθ)`；
2. 点在圆上对称、旋转，坐标会跟着换位置、换符号；
3. 连续转过两个角，等于一次转过这两个角的和。

> 会背公式，只能解决还记得公式时的题；会生成公式，才能解决忘了公式时的题。

---

## 01｜单位圆为什么能控制三角函数（01—08）

半径为1、圆心在原点的圆，从 x 轴正方向逆时针转过角 θ，落点 Pθ：

```text
01  Pθ = (cosθ, sinθ)          ← 点在单位圆上
02  sin²θ + cos²θ = 1          ← 单位圆方程（勾股定理）
03  tanθ = sinθ / cosθ         ← 连线斜率 = 纵/横
04  cotθ = cosθ / sinθ
05  secθ = 1 / cosθ
06  cscθ = 1 / sinθ
```

公式02分别除以 cos²θ 和 sin²θ：

```text
07  1 + tan²θ = sec²θ
08  1 + cot²θ = csc²θ
```

**边界**：分母不能为0；sec、csc 是**倒数函数**，不是反余弦、反正弦（反三角函数写作 arccos、arcsin）。

## 02｜诱导公式 = 对称 + 旋转 + 看象限（09—16）

不背"奇变偶不变"，先看**点去了哪里**。三种动作：对称、旋转、看象限。

**−θ：关于横轴对称**（横不变，纵变号）：

```text
09  sin(−θ) = −sinθ
10  cos(−θ) =  cosθ
11  tan(−θ) = −tanθ
```

即：正弦、正切是奇函数，余弦是偶函数。

**多转一整圈：回到原点位**：

```text
12  sin(θ + 2π) = sinθ       （一般式 2kπ）
13  cos(θ + 2π) = cosθ
14  tan(θ + π)  = tanθ       （正切周期是 π，一般式 kπ，k∈ℤ）
```

**π − θ：关于纵轴对称**（纵不变，横变号）：

```text
15  sin(π − θ) =  sinθ
16  cos(π − θ) = −cosθ
```

> 正负号从来不是口诀"规定"的，它只是在报告：新点落在哪个象限，横、纵坐标分别是正还是负。

## 03｜两个旋转怎样合成 → 母公式（17—22）

先转 α 再转 β，效果等于一次转 α+β。用旋转矩阵：

```text
R(α+β) = R(α) · R(β)
[cos(α+β) −sin(α+β); sin(α+β) cos(α+β)]
 = [cosα −sinα; sinα cosα] · [cosβ −sinβ; sinβ cosβ]
```

对照相同位置，得到**母公式**：

```text
17  sin(α + β) = sinα cosβ + cosα sinβ
18  sin(α − β) = sinα cosβ − cosα sinβ
19  cos(α + β) = cosα cosβ − sinα sinβ
20  cos(α − β) = cosα cosβ + sinα sinβ
```

用 `tan x = sin x / cos x`，分子分母同除 `cosα cosβ`：

```text
21  tan(α + β) = (tanα + tanβ) / (1 − tanα tanβ)
22  tan(α − β) = (tanα − tanβ) / (1 + tanα tanβ)
```

**易错**：余弦和角中间是**减号**，差角中间反而是**加号**。正切是"分子同号，分母反号"（记忆提示，使用前仍要检查原式和分母是否有定义）。

## 04｜倍角与半角 = 换个代入（23—32）

和角公式里令 α = β = θ，倍角自动出现：

```text
23  sin 2θ = 2 sinθ cosθ
24  cos 2θ = cos²θ − sin²θ
25  cos 2θ = 2cos²θ − 1        ← 用 sin²+cos²=1
26  cos 2θ = 1 − 2sin²θ
27  tan 2θ = 2tanθ / (1 − tan²θ)
```

把25、26反过来整理，得降幂与半角：

```text
28  sin²θ = (1 − cos 2θ) / 2
29  cos²θ = (1 + cos 2θ) / 2
30  sin(θ/2) = ± √((1 − cosθ)/2)
31  cos(θ/2) = ± √((1 + cosθ)/2)
32  tan(θ/2) = sinθ/(1 + cosθ) = (1 − cosθ)/sinθ
```

**半角最大的坑在根号外的 ±**：θ 在哪个象限不能直接决定 θ/2 的符号，必须先确定**半角所在象限**再选正负。公式32的两个分式不是在每个点都同时有定义，要分别检查分母。

## 05｜积化和差、和差化积 = 母公式相加减（33—40）

余弦和角、差角相加/相减：

```text
33  sinα sinβ = [cos(α−β) − cos(α+β)] / 2
34  cosα cosβ = [cos(α−β) + cos(α+β)] / 2
```

正弦和角、差角相加/相减：

```text
35  sinα cosβ = [sin(α+β) + sin(α−β)] / 2
36  cosα sinβ = [sin(α+β) − sin(α−β)] / 2
```

**最常见错误：忘记右边的 1/2。**

反过来，令 α=(A+B)/2, β=(A−B)/2（即 A=α+β, B=α−β），得和差化积：

```text
37  sin A + sin B =  2 sin((A+B)/2) cos((A−B)/2)
38  sin A − sin B =  2 cos((A+B)/2) sin((A−B)/2)
39  cos A + cos B =  2 cos((A+B)/2) cos((A−B)/2)
40  cos A − cos B = −2 sin((A+B)/2) sin((A−B)/2)
```

**公式40前面的负号最容易漏**。不要孤立地记：把 A=B 代进去，左边是0右边也应是0；再取一个简单角快速验算，符号错误当场暴露。

## 06｜40个公式一页收齐（树根→树叶）

```text
Ⅰ 同角关系与定义（01—08）
   Pθ=(cosθ,sinθ)   sin²θ+cos²θ=1
   tanθ=sinθ/cosθ   cotθ=cosθ/sinθ
   secθ=1/cosθ      cscθ=1/sinθ
   1+tan²θ=sec²θ    1+cot²θ=csc²θ

Ⅱ 对称、周期与诱导（09—16）
   sin(−θ)=−sinθ  cos(−θ)=cosθ  tan(−θ)=−tanθ
   sin(θ+2π)=sinθ cos(θ+2π)=cosθ tan(θ+π)=tanθ
   sin(π−θ)=sinθ  cos(π−θ)=−cosθ

Ⅲ 和差角（17—22）
   sin(α±β) = sinαcosβ ± cosαsinβ
   cos(α±β) = cosαcosβ ∓ sinαsinβ
   tan(α±β) = (tanα ± tanβ)/(1 ∓ tanαtanβ)

Ⅳ 倍角（23—27）
   sin2θ = 2sinθcosθ
   cos2θ = cos²θ−sin²θ = 2cos²θ−1 = 1−2sin²θ
   tan2θ = 2tanθ/(1−tan²θ)

Ⅴ 降幂与半角（28—32）
   sin²θ = (1−cos2θ)/2
   cos²θ = (1+cos2θ)/2
   sin(θ/2) = ±√((1−cosθ)/2)
   cos(θ/2) = ±√((1+cosθ)/2)
   tan(θ/2) = sinθ/(1+cosθ) = (1−cosθ)/sinθ

Ⅵ 积化和差（33—36）
   sinαsinβ = [cos(α−β)−cos(α+β)]/2
   cosαcosβ = [cos(α−β)+cos(α+β)]/2
   sinαcosβ = [sin(α+β)+sin(α−β)]/2
   cosαsinβ = [sin(α+β)−sin(α−β)]/2

Ⅶ 和差化积（37—40）
   sinA+sinB =  2sin((A+B)/2)cos((A−B)/2)
   sinA−sinB =  2cos((A+B)/2)sin((A−B)/2)
   cosA+cosB =  2cos((A+B)/2)cos((A−B)/2)
   cosA−cosB = −2sin((A+B)/2)sin((A−B)/2)
```

> 全文等式都应在相应函数与分式有定义时使用；涉及 π 的公式默认采用弧度制。

## 07｜考场忘了公式，按这3步重建

1. **把角放回单位圆**：横坐标看余弦，纵坐标看正弦，斜率看正切。
2. **判断它经历了什么动作**：关于坐标轴对称？转过半圈/一圈？还是连续转过两个角？
3. **从母公式代入**：倍角 = 令两角相等；半角 = 倍角式反向整理；积化和差 = 和差角公式相加减。

**最小记忆包（三行）**：

```text
Pθ = (cosθ, sinθ)
sin²θ + cos²θ = 1
sin(α+β) = sinαcosβ + cosαsinβ
cos(α+β) = cosαcosβ − sinαsinβ
```

> 三角函数真正要学会的，不是记住40个答案，而是在需要时重新生成答案。
