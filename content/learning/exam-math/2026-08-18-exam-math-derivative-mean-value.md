# 数学：导数与中值定理，局部斜率怎样变成区间结论

> 【本卡片解决】为什么只看 `f'(x)`，就能判断函数在整个区间上的单调性、极值和不等式关系。

## 01｜导数是一把局部尺子

```text
f'(x) > 0       函数在该点附近向上走
f'(x) < 0       函数在该点附近向下走
f''(x) > 0      斜率在增大，图像偏“向上弯”
f''(x) < 0      斜率在减小，图像偏“向下弯”
```

导数给的是局部信息。要把它升级为区间结论，需要连续、可导等条件，以及中值定理提供的“某个中间点”。

## 02｜三类中值定理怎么选

| 定理 | 结构 | 题目常见信号 |
|---|---|---|
| 罗尔 | 两端函数值相等 | 证明存在 `c` 使 `f'(c)=0` |
| 拉格朗日 | `f(b)-f(a)` 与 `f'(c)` 相连 | 单调性、不等式、根的个数 |
| 柯西 | 两个函数的增量作比 | 分子分母结构、参数消去 |

拉格朗日中值定理的核心关系是：

`f(b) - f(a) = f'(c)(b-a)`，其中 `c` 位于 `(a,b)`。

它不是说“导数等于平均变化率的每一个点”，而是说至少存在一个中间点实现平均变化率。

## 03｜证明不等式的标准动作

1. 把目标移到一边，构造辅助函数 `F(x)`。
2. 求 `F'(x)`，寻找它的符号或单调性。
3. 用中值定理、极值定理或端点值完成区间结论。

如果题目含有 `f(x)-f(y)`，优先考虑拉格朗日；如果含有两个函数的比值变化，考虑柯西；如果要证明根的存在性，先看连续性，再用介值定理。

## 04｜极值不等于最大值

驻点 `f'(x)=0` 只是候选点。判断极值要看导数在点两侧的符号变化：

```text
正 → 负       极大值
负 → 正       极小值
不变号        不一定有极值
```

闭区间最值还必须比较端点。把“局部极值”“区间最值”“驻点”混成一个词，是导数题的高频失分点。

## 一句话结论

导数负责描述局部斜率，中值定理负责把局部信息搬到区间；解题时先画出这条桥，再开始计算。
