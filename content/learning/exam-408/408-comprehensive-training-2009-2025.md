## 2009年第42题｜数据结构｜15分

**状态**：首次口述和代码尝试已完成；参考答案已讲解；需独立二刷。  
**难度**：基础/典型。  
**原题来源**：《01_计算机408真题及答案_2009-2025.pdf》PDF第4页。  
**建议限时**：20分钟。**实际耗时**：未精确记录。  
**考点（解题后解锁）**：带头结点单链表、倒数第k个结点、快慢指针、越界、指针操作、时间/空间复杂度。

### 原题

已知一个带有表头结点的单链表，结点结构为`data | link`。假设该链表只给出了头指针 `list`。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第 `k` 个位置上的结点（`k` 为正整数）。若查找成功，算法输出该结点的 `data` 域的值，并返回1；否则，只返回0。

要求：（1）描述算法的基本设计思想；（2）描述算法的详细实现步骤；（3）采用C、C++或Java描述算法，关键之处简要注释。

### 用户独立口述原文（保留证据）

> “这个简单，就是双指正，一个向前走k个，一个在起点，然后一起走，等第一个到终点后，再返回第二个位置”

补充边界讨论，数据链表 `head → 10 → 20 → 30 → 40 → NULL`：

> “10 吧，不过这个是4个节点唉” （对k=5指出只有4个数据结点）  
> “40， 10  ，返回 10” （对k=4的快指针步数产生一处偏差，但倒数第4个结点判断正确）  
> “那干脆移动k-1次好了”

上述改用 `k-1` 次移动是用户独立提出的、更适合其直觉的实现版本。

### 用户原始代码（未经修正）

```cpp
struct Node {
    int data;
    Node* link;
};

public void main(){

    Node nodefast = list.link;

    Node nodeslow =  list.link;

    while(n>k-1){
        nodefast = nodefast.link;
        n++;
    }

    while(nodefast.next != null){
        nodefast = nodefast.link;
        nodeslow = nodeslow.link;
    }

    return nodeslow;
}
```

### 判断和第一处关键错误

- **独立突破口：有。** 双指针一趟扫描思想正确，达到了O(n)时间、O(1)额外空间的目标。
- **代码第一处关键问题**：`n` 未定义/初始化，且 `while(n>k-1)` 比较方向错误，不能按希望的次数移动快指针。
- **后续问题**：混用Java和C++语法（`public void main`、`Node` vs `Node*`、`.` vs `->`、`null` vs `nullptr`）；字段名原本是 `link`，却写了 `next`；没有处理 `k` 超长/空表；题目要求输出数据并返回整数1/0，而非直接返回结点。
- **边界认知**：准确指出头结点不计入数据结点、长度4时倒数第5个不存在；首次把“走到第4个结点”与“移动4次”混淆，后自行改为先走 `k-1` 次。
- **估分**：设计思想5/5；原始提交代码如果直接交卷，整题暂估8—10/15。这是训练估分，不代表正式阅卷；详细步骤/代码尚未独立完成，因此不记15/15。
- **用户选择**：数据结构编码后续优先用408允许的**C++**（可以用Java做语言迁移解释），避免纯C语法成本。

### 讲解后的参考解答（C++；采用用户提出的k-1版本）

设计步骤：

1. `fast`、`slow` 都从头结点的后继（第一个数据结点）出发。
2. `fast` 先走 `k-1` 次，途中若走不够则返回0。
3. 如果 `fast` 为空，说明长度小于k，返回0。
4. 当 `fast->link != nullptr` 时，两指针同时前进。
5. 输出 `slow->data` 并返回1，且不改动原链表。

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* link;
};

int Search_k(Node* list, int k) {
    if (list == nullptr || k <= 0) return 0;

    Node* fast = list->link;
    Node* slow = list->link;

    for (int i = 0; i < k - 1; ++i) {
        if (fast == nullptr) return 0;
        fast = fast->link;
    }
    if (fast == nullptr) return 0;

    while (fast->link != nullptr) {
        fast = fast->link;
        slow = slow->link;
    }

    cout << slow->data << endl;
    return 1;
}
```

**复杂度**：`O(n)`时间，`O(1)`额外空间。

**二刷要求**：不看上面代码，独立使用C++完成；特别核查空表、`k=1`、`k=n`、`k>n`；按原题15分重新评分。

### 原题

某计算机的 CPU 主频为500MHz，CPI为5（即执行每条指令平均需5个时钟周期）。假定某外设的数据传输率为0.5MB/s，采用中断方式与主机进行数据传送，以32位为传输单位，对应的中断服务程序包含18条指令，中断服务的其他开销相当于2条指令的执行时间。请回答下列问题，要求给出计算过程。

（1）在中断方式下，CPU用于该外设I/O的时间占整个CPU时间的百分比是多少？

（2）当该外设的数据传输率达到5MB/s时，改用DMA方式传送数据。假定每次DMA传送块大小为5000B，且DMA预处理和后处理的总开销为500个时钟周期，则CPU用于该外设I/O的时间占整个CPU时间的百分比是多少？（假设DMA与CPU之间没有访存冲突）

### 用户独立口述（2026-11-02，第1问进行中）

> “其实不太会说这种话，但是我能猜到中段模式下，让我想想。哦，它美中，它每次要发一次数据都要跟 CPU说一下，然后 CPU处理，然后再发回来。这跟 DMA不一样，DMA就第一次和最后一次可能需要 CPU介入，中间都是直接发的。让我看一下这个地方。这里的 DMA服务是 8加2等于 20条。那么说白了就需要知道 DMA一次要传多少条数据嘛，一共要传多少次。如果不考虑其他指令的话，那应该是 32位为传输单位，说白了就是 4B嘛，4B，4大B的那个传输。但是传输速率为 0.5兆每秒。这个地方我就不知道细节到底该怎么算了，这里的几个数据的含义”

**当时诊断（仅评价思路，不含答案）**：

- **已独立理解**：中断需要CPU干预，DMA按数据块传送、CPU主要做开始和结束的控制；32位=4B。
- **第一个关键错误**：把原题“18条中断服务指令 + 相当于2条指令的额外开销”误称为DMA开销，并口误为“8+2”；正确应区分“20条等效指令用于一次中断服务”与“DMA的500个时钟周期/块”。
- **当前卡点**：尚不能把数据传输率(B/s)转换为中断频率(次/s)，也还没建立主频、CPI、指令数与CPU时间占比的单位关系。
- **已给最小提示**：解释500MHz、CPI=5、0.5MB/s、32位、18+2条等效指令各自代表什么，追问“0.5MB/s每次4B，一秒需要中断多少次？”。
