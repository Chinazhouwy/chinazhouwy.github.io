# 考研 408 综合卡：一次请求如何穿过四门课

> 【场景】程序调用一个网络 API。不要从“HTTP 是第几层”开始背，先沿着数据真正经过的路径走一遍。

## 01｜用户态到内核态

```text
应用程序构造请求数据
  ↓ 调用 socket / write 等系统调用
CPU 进入内核态
  ↓ 操作系统检查进程权限、缓冲区和文件描述符
协议栈接管字节
```

这里出现三个学科边界：程序中的缓冲区属于数据组织问题；系统调用和进程状态属于操作系统；CPU 从用户态进入内核态涉及组成原理和特权级。

## 02｜数据如何变成报文

```text
HTTP 请求
  ↓ TCP 切分为字节流并编号
IP 数据报选择逻辑地址
  ↓ 链路层封装帧
网卡发送比特流
```

每一层增加自己的控制信息，也只处理自己负责的边界。TCP 不知道路由怎么走，IP 不保证可靠到达，链路层也不理解应用层的 URL。

## 03｜服务器端发生什么

服务器网卡收到比特后，数据沿协议栈反向解封装，TCP 根据端口交给对应 socket，操作系统唤醒等待中的线程，应用程序读取请求并生成响应。

如果题目问“哪个结构保存等待连接”，关注操作系统和网络套接字；如果问“哪个字段标识下一段数据”，关注 TCP 序号和确认号；如果问“数据从内存如何送到设备”，再回到 DMA、总线和中断。

## 04｜一张综合题检查表

| 题目问法 | 优先定位 |
|---|---|
| 最短路径、遍历、复杂度 | 数据结构 |
| Cache、指令、总线、DMA | 组成原理 |
| 进程、线程、页表、系统调用 | 操作系统 |
| 分层、TCP、IP、路由、HTTP | 计算机网络 |

## 一句话结论

综合题不是把四科名词混在一起，而是沿着“程序数据 → 系统调用 → 协议栈 → 硬件传输”定位每一步的责任边界。
