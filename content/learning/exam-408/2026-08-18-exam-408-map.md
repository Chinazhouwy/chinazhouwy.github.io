# 计算机基础：从一行代码到一个数据包的四科地图

> 【卡片封面】计算机基础不是四本书的并列背诵，而是一台计算机如何保存数据、执行指令、管理资源并完成通信。

## 01｜四科各自回答一个问题

| 科目 | 核心问题 | 常见对象 |
|---|---|---|
| 数据结构 | 数据如何组织，操作如何更快 | 数组、链表、树、图、排序 |
| 组成原理 | 指令如何变成硬件动作 | CPU、存储器、Cache、总线 |
| 操作系统 | 多个程序如何共享机器 | 进程、线程、虚拟内存、文件 |
| 计算机网络 | 不同机器如何交换信息 | TCP、IP、路由、HTTP |

## 02｜四科贯通图

```text
源程序
  ↓ 编译为指令
CPU 执行 + Cache / 内存
  ↓ 进程通过系统调用申请资源
操作系统管理进程、地址空间和文件
  ↓ socket 进入协议栈
TCP / IP / 链路层把字节送到另一台机器
```

看到综合题，先问它的边界：是在讨论数据组织、硬件执行、资源管理，还是通信协议。边界判断正确，后面的公式才不会串科。

## 03｜建议的复习顺序

1. 数据结构先建立复杂度和基本结构直觉。
2. 组成原理理解数据如何在寄存器、Cache、主存间移动。
3. 操作系统把硬件资源抽象为进程、地址空间和文件。
4. 网络从分层、可靠传输和路由开始，再回到应用层。
5. 最后用“程序发起一次请求”把四科重新串起来。

## 一句话结论

计算机基础的关键能力来自“结构识别”：先判断数据在哪里、谁在管理、如何流动，再理解对应的结论。
