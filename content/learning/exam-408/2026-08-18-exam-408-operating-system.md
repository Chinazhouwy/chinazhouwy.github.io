# 考研 408 操作系统：进程、线程与虚拟内存，谁在管理什么

> 【本卡片解决】进程和线程到底差在哪里，以及虚拟内存为什么能让程序看到一个连续地址空间。

## 01｜进程是资源边界，线程是执行单元

```text
进程：独立地址空间 + 资源归属 + 运行状态
线程：进程内部的执行流，共享进程资源
```

线程通常共享代码段、数据段和打开的文件，但拥有自己的程序计数器、寄存器集合和栈。线程切换不意味着完全没有代价，只是通常不需要切换整个地址空间。

## 02｜上下文切换切换了什么

调度器让 CPU 从一个执行流转到另一个执行流，需要保存当前上下文并恢复目标上下文。题目问“切换开销”时，先判断是否发生地址空间切换、缓存失效或内核态切换，不要把所有开销都简化成保存几个寄存器。

## 03｜虚拟地址如何落到物理地址

```text
虚拟地址 = 页号 + 页内偏移
       ↓ 查 TLB / 页表
物理地址 = 物理页框号 + 页内偏移
```

页内偏移在地址转换过程中保持不变。TLB 命中时可以快速得到页框号；TLB 未命中但页表项存在时，需要查页表并更新 TLB；页表项无效时触发缺页异常。

## 04｜缺页不是普通函数调用

```text
访问虚拟页
  ↓ 不在内存
缺页异常 → 内核检查合法性 → 找空闲页框/选择牺牲页
  ↓ 必要时写回磁盘
从磁盘调入目标页 → 更新页表 → 重新执行被中断指令
```

重新执行是关键：异常处理完成后，原指令通常可以从头再来。题目若改变页面访问序列或页框数量，要重新模拟替换过程，不能只套“页框越多缺页越少”的直觉。

## 05｜死锁的四个必要条件

互斥、请求并保持、不可剥夺、循环等待同时成立，才可能发生死锁。破坏任意一个条件，都可以从系统设计上阻止死锁；检测、避免和预防是不同策略。

## 一句话结论

操作系统题先问“资源归谁、执行由谁推进、地址如何翻译”，再选择进程、线程、页表或死锁的具体知识点。
